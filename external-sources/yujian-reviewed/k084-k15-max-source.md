# K15 Max

## 产品定位
更薄、更轻、更高效的 75% 配列无线机械键盘

## 目标用户
- 追求便携与桌搭质感的轻薄键盘用户
- 多设备办公与居家办公用户
- Mac 与 Windows 双系统切换用户
- 需要低噪音、低延迟的办公与轻游戏用户

## 核心卖点
- 超薄机身设计：前缘高度仅 11.5mm，搭配 Gateron 矮轴，实现极致轻薄体验
- 三模连接自由切换：2.4GHz / 蓝牙 5.1 / Type-C 有线，多设备无缝流转
- Mac 与 Windows 双系统原生支持，键位布局与系统快捷键无缝适配

## 其他卖点
- 连接方式：2.4GHz / 蓝牙 5.1 / Type-C 有线
- 回报率：蓝牙模式 90Hz
- 配列：75% (90 键)，ANSI 布局
- 轴体：Gateron 矮轴（North-facing）
- 键帽：Low-profile double-shot PBT 键帽
- 电池：2000mAh 锂电池，关背光续航约 95 小时，开 RGB 最低亮度约 50 小时
- 背光：22 种 RGB 背光模式，支持自定义
- 软件：支持 QMK / VIA 改键与宏定义
- 系统兼容：macOS / Windows / Linux
- 无冲：有线与无线模式下均支持全键无冲
- 尺寸：370 x 143 mm，重量 700g
- 打字角度：2.7º / 3.9º / 6.1º 可调
- 工作温度：-10 至 50℃

## 解释
K15 Max 适合追求桌面整洁与高效多设备切换的用户，超薄机身与矮轴设计带来舒适的低角度打字体验，同时不牺牲机械键盘的手感与反馈。
相比传统机械键盘，K15 Max 在保持 75% 配列实用性的同时，大幅降低厚度与重量，更易携带，且支持 2.4GHz 无线低延迟连接，兼顾办公与轻游戏场景。
对于 Mac 用户，K15 Max 提供了原生 macOS 键位与快捷键支持，无需额外设置即可无缝上手。
