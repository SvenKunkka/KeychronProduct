# V4 Max

## 产品定位
面向 60% 配列爱好者的三模无线机械键盘，兼顾性能与便携。

## 目标用户
- 60% 配列爱好者
- 多设备办公用户
- 桌面空间有限但追求性能的游戏玩家

## 核心卖点
- 三模连接（蓝牙5.1、2.4GHz、有线），支持多设备无缝切换
- Gasket Mount 结构，搭配 PC 定位板，提供柔和一致的手感与悦耳声音
- 4000mAh 大电池，关背光续航长达 190 小时，开 RGB 也能用 100 小时

## 其他卖点
- 连接方式：蓝牙 5.1 / 2.4GHz / 有线（Type-C）
- 回报率：1000Hz（2.4GHz 和有线）/ 90Hz（蓝牙）
- 配列：60%
- 轴体：Gateron Jupiter（整装版）
- 键帽：Double-shot PBT，OSA 高度（OEM 高度，SA 形状），不透明
- 热插拔：兼容大部分 3 针/5 针 MX 机械轴（如 Gateron、Cherry MX、Kailh）
- 卫星轴：螺丝固定 PCB 卫星轴
- 电池：4000mAh 锂聚合物电池，充电时间约 5 小时
- 软件：支持 QMK（通过 ARM Cortex-M4 主控）
- RGB：South-facing RGB LED
- 无冲：无线和有线均支持全键无冲
- 系统兼容：Windows / macOS / Linux
- 其他：Gasket Mount 结构，PC 定位板，ABS 塑料外壳，倾斜角度 3.5°/8°/11°

## 解释
V4 Max 是 Keychron 面向 60% 配列爱好者的三模无线键盘，将紧凑布局与高性能无线技术结合，适合桌面空间有限但追求效率与便携的用户。相比传统 60% 键盘，它提供了 Gasket Mount 结构、4000mAh 大电池和 1000Hz 回报率，在打字体验和无线性能上都有显著提升。对于需要多设备切换、长时间续航和稳定连接的办公用户，V4 Max 是一个值得考虑的选择。
