# Q14 Max

## 产品定位
把铝合金质感、三模连接和全尺寸布局结合在一起的桌面型键盘

## 目标用户
- 机械键盘发烧友
- 高端电竞玩家
- 多设备办公用户
- 桌面美学追求者

## 核心卖点
- 全铝合金机身，CNC 一体成型，坚固耐用且质感出众
- 三模连接（2.4GHz/蓝牙/Type-C），1000Hz 回报率，游戏办公两不误
- 4000mAh 大电池，RGB 最低亮度下续航长达 100 小时

## 其他卖点
- 连接方式：2.4GHz / 蓝牙 / Type-C 有线
- 回报率：1000Hz（2.4GHz & 有线）/ 90Hz（蓝牙）
- 配列：全尺寸
- 产品尺寸：157 × 445 mm
- 轴体：Gateron Jupiter 轴，热插拔设计
- 键帽：PC 定位板，南向 RGB
- 电池：4000mAh 锂聚合物电池，续航最高 300 小时（关灯）
- 软件：支持 QMK / VIA 改键
- 系统：兼容 macOS / Windows / Linux

## 解释
Q14 Max 适合追求桌面统一质感与高效输入的用户，全铝合金机身带来沉稳手感，三模连接满足多设备切换需求。相比普通塑料键盘，它在材质和续航上优势明显，是办公与游戏的均衡之选。
