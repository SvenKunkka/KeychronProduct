# Q2 Pro

## 产品定位
把 CNC 铝材质感、无线自由和 65% 紧凑布局结合在一起的桌面型键盘

## 目标用户
- 追求桌面质感的机械键盘发烧友
- 多设备办公与居家办公用户
- Mac 用户（macOS/Windows/Linux 兼容）
- 紧凑布局爱好者（65% 配列）

## 核心卖点
- 全 CNC 铝制外壳，一体成型，质感与耐用性兼得
- 4000mAh 大电池，无线续航最长 300 小时（关背光）
- 蓝牙 5.1 + 1000Hz 有线回报率，兼顾办公与游戏

## 其他卖点
- 连接方式：蓝牙 5.1 / Type-C 有线
- 回报率：1000 Hz（有线）/ 90 Hz（无线）
- 配列：65% 紧凑布局
- 轴体：Keychron K Pro 热插拔轴，兼容 3 针/5 针 MX 轴（Gateron、Cherry、Kailh 等）
- 键帽：KSA 双色注塑 PBT 键帽，不透光
- 电池：4000 mAh 锂聚合物电池
- 续航：关背光最长 300 小时，开 RGB 最低亮度最长 100 小时
- 软件：QMK/VIA 支持，可自定义键位和宏
- RGB：南向 RGB LED
- 声学：PC 定位板 + 螺丝固定 PCB 卫星轴，填充结构
- 系统兼容：macOS / Windows / Linux

## 解释
Q2 Pro 适合那些想要紧凑桌面布局，又不愿牺牲质感与无线体验的用户。全 CNC 铝制外壳带来扎实的金属手感，65% 配列节省桌面空间，同时保留方向键和常用功能键。
相比入门级塑料键盘，Q2 Pro 在材质和做工上明显高出一档；相比同价位竞品，其 4000mAh 电池和 300 小时续航（关背光）在无线键盘中属于领先水平，且支持 QMK/VIA 开源改键，可玩性更强。
它不是一把纯游戏键盘，也不是纯办公键盘，而是兼顾品质、无线和自定义的桌面全能型选择。
