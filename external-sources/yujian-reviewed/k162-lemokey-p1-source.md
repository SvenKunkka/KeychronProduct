# Lemokey P1 产品资料修复草稿（待审核）

> 本文用于同名替换 02 中字段较少的 P1 文档，并与 P1 Pro 无线版本彻底分离。审核通过前不会进入产品事实账本。

## 产品定位

75% 全 CNC 铝制、Type-C 纯有线 QMK/VIA 客制化游戏键盘。

## 核心卖点

- P1 是 Type-C 纯有线版本，不具备 2.4 GHz、Bluetooth、电池或续航字段。
- 有线回报率为 1000 Hz。
- 全 CNC 铝制机身、PC 定位板，支持热插拔。
