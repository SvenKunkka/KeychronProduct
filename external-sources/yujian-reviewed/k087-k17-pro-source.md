# K17 Pro

## 产品定位
更轻薄、更便携、更容易融入桌搭的 96% 配列低剖面机械键盘

## 目标用户
- 追求轻薄桌搭的办公用户
- 多设备切换的移动办公人群
- 入门机械键盘用户
- Mac 用户

## 核心卖点
- 超薄机身：前高仅 8.27mm，搭配低剖面轴体和键帽，打造极简桌面风格
- 96% 配列：保留数字小键盘，节省桌面空间，办公效率与桌面美学兼得
- Gateron 低剖面轴体：短键程、轻触发，长时间打字更省力

## 其他卖点
- 连接方式：蓝牙 5.1 和 Type-C 有线双模
- 回报率：有线 1000Hz，无线 90Hz
- 配列：103键 (96%)，ANSI 布局
- 键帽：低剖面双色注塑 PBT，耐磨不打油
- 电池：2000mAh 锂聚合物电池，关背光续航约 130 小时，开 RGB 约 65 小时（最低亮度）
- 背光：22 种 RGB 灯效，支持自定义
- 软件：支持 QMK/VIA 改键和宏定义
- 系统兼容：macOS/Windows/Linux，支持 Mac/Win 双系统切换
- 其他：全键无冲（有线/无线均支持），12 个多媒体键，三段式脚撑（2.48°/3.94°/6.30°）

## 解释
K17 Pro 不是一把厚重的全尺寸键盘，而是一款将 96% 配列与低剖面设计结合的轻薄键盘。它适合那些需要数字小键盘但桌面空间有限的用户，尤其是办公和轻度游戏场景。相比传统全尺寸键盘，K17 Pro 更薄更轻（679g），搭配蓝牙 5.1 和长续航，可以轻松在台式机、笔记本和平板之间切换。对于 Mac 用户，它原生支持 macOS 布局，开箱即用。
