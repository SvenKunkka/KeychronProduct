# C1 Pro

## 产品定位
更可靠、更舒适、更容易上手的 80% 配列机械键盘

## 目标用户
- 入门机械键盘用户
- 办公与轻游戏用户
- 预算有限但追求品质的用户

## 核心卖点
- Tray Mount 结构，手感稳定一致
- Keychron K Pro 轴体，出厂润滑，顺滑耐用
- South-facing RGB，兼容 Cherry 高度键帽，灯光效果更佳

## 其他卖点
- 连接方式：Type-C 有线连接，附带 Type-C 转 Type-A 转接头
- 回报率：1000 Hz
- 配列：80%（TKL），紧凑节省桌面空间
- 轴体：Keychron K Pro 轴，支持热插拔（5 脚和 3 脚）
- 键帽：OEM 高度双色注塑 PBT 键帽，耐磨不打油
- 背光：South-facing RGB LED
- 卫星轴：钢板卫星轴，大键更稳定
- 外壳：ABS 塑料，轻量化设计（约 700g）
- 倾斜角度：4.8° / 8.5° / 10.7°，三档可调
- 系统兼容：Mac/Win 双系统，附赠适配键帽

## 解释
C1 Pro 是面向初次接触机械键盘的用户，以及需要兼顾办公与轻游戏的用户的理想选择。它采用 Tray Mount 结构，提供一致且稳定的敲击手感，同时 Keychron K Pro 轴体出厂润滑，开箱即用，无需额外调教。相比同价位产品，C1 Pro 在细节上更用心：South-facing RGB 让灯光效果更均匀，且兼容 Cherry 高度键帽，方便后续 DIY；双色注塑 PBT 键帽耐磨耐用，长期使用也不易打油。对于预算有限但不愿妥协品质的用户，C1 Pro 以亲民价格提供了扎实的做工和实用的功能，是入门机械键盘的可靠之选。
