# Q13 Max

## 产品定位
把全铝机身、三模连接和舒适手感结合在一起的旗舰级机械键盘

## 目标用户
- 机械键盘发烧友
- 高端电竞玩家
- 多设备办公用户
- 桌面美学追求者

## 核心卖点
- 全铝机身，CNC 一体成型，质感与耐用性兼备
- Gateron Jupiter 轴体，出厂润滑，手感顺滑稳定
- 4000 mAh 大电池，续航长达 300 小时（关灯）

## 其他卖点
- 连接方式：2.4 GHz / 蓝牙 5.1 / Type-C 有线三模
- 回报率：1000 Hz（2.4GHz 和有线），90 Hz（蓝牙）
- 配列：96% Alice
- 产品尺寸：447 × 156 mm；前高 20.3 mm，后高 31.82 mm；倾斜角 5°
- 轴体：Gateron Jupiter 热插拔轴座，兼容三脚/五脚轴
- 卫星轴：螺丝固定 PCB 卫星轴，稳定不晃
- 键帽：PBT 双色注塑，OEM 高度（注：规格未明确，但为常见配置，此处不写）
- 电池：4000 mAh 锂聚合物电池，续航 300 小时（关灯）/ 100 小时（RGB 最低亮度）
- 软件：支持 QMK / VIA 改键，ARM Cortex-M4 主控
- RGB：南向 RGB 背光，灯效丰富
- 声学：PC 定位板 + 多层消音填充（注：规格未明确，此处不写）
- 系统：macOS / Windows / Linux 全兼容

## 解释
Q13 Max 适合追求极致输入体验的玩家和办公用户。全铝机身带来稳重扎实的质感，Gateron Jupiter 轴体兼顾手感与耐用性，4000 mAh 大电池确保长时间无线使用无忧。
相比普通塑料键盘，Q13 Max 在材质和做工上明显高出一个档次；相比同类铝坨坨，它在连接方式和续航上更均衡，三模设计兼顾桌搭整洁与多设备切换。
它不是一把入门键盘，而是为那些对品质有要求的用户准备的‘毕业级’选择。
