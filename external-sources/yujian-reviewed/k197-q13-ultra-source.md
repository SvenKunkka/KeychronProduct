# Q13 Ultra

## 产品定位
把性能、连接和质感结合在一起的旗舰型键盘

## 目标用户
- 机械键盘发烧友
- 高端电竞玩家
- 桌面创作者（Desk Setup）
- 收藏用户 / 礼品市场

## 核心卖点
- CNC 铝合金外壳与 PC 定位板，兼顾刚性与柔韧手感
- Keychron Silk POM 轴体，出厂润滑，顺滑稳定
- 8000 Hz 回报率（有线 & 2.4GHz），电竞级响应速度

## 其他卖点
- 连接方式：2.4 GHz / Bluetooth 5.3 / Type-C 有线
- 回报率：8000 Hz（有线 & 2.4GHz），125 Hz（蓝牙）
- 配列：全尺寸
- 产品尺寸：156.9 × 447.3 mm
- 轴体：Keychron Silk POM Switch，热插拔
- 键帽：PBT 材质（规格未明确，但为 Keychron 标准）
- 电池：4000 mAh 锂聚合物电池，续航最高 660 小时（关背光）/ 200 小时（RGB 最低亮度）
- 软件：QMK / VIA 支持（规格未明确，但为 Keychron 标准）
- RGB：South-facing RGB LED
- 声学：PC 定位板 + 螺丝固定 PCB 卫星轴，优化声音
- 系统兼容：macOS / Windows / Linux

## 解释
Q13 Ultra 是一款面向追求极致性能与桌面美学的用户打造的旗舰机械键盘。它采用 CNC 铝合金外壳，提供扎实的质感，同时 PC 定位板与 Silk POM 轴体带来柔韧且顺滑的敲击体验，适合长时间办公与高强度游戏。
相比普通机械键盘，Q13 Ultra 在无线模式下也能提供 8000 Hz 的回报率，显著降低延迟，满足电竞玩家对响应速度的苛刻要求。同时，4000 mAh 大电池与多系统兼容性，使其成为 Mac 与 Windows 用户都能无缝使用的全能旗舰。
它不是一把普通的键盘，而是 Keychron 对工艺与性能的极致表达，适合那些已经拥有键盘但追求更高品质与独特品味的用户。
