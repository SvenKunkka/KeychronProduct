# R3

## 产品定位
更轻巧、更持久、更容易多设备切换的 80% 配列三模机械键盘

## 目标用户
- 办公+轻游戏用户
- 多设备办公用户
- 追求便携与桌面整洁的用户
- macOS/Windows/Linux 多系统用户

## 核心卖点
- 4000mAh 大电池，关背光续航约 310 小时，告别频繁充电
- 三模连接（2.4GHz / 蓝牙 5.3 / Type-C），多设备无缝切换
- Keychron Super 机械轴，手感顺滑，办公游戏两相宜

## 其他卖点
- 连接方式：2.4GHz / 蓝牙 5.3 / Type-C 有线
- 回报率：蓝牙模式 125Hz
- 配列：84 键 80% 布局，ANSI 标准
- 轴体：Keychron Super 机械轴，South-facing 设计
- 键帽：Double-shot PBT 材质，Cherry 高度，经久耐用
- 电池：4000mAh 可充电锂电池，关背光续航约 310 小时
- 背光：24 种 RGB 灯效，支持自定义
- 系统兼容：macOS / Windows / Linux
- 多媒体键：12 个，提升操作效率
- 无冲模式：有线和无线均支持全键无冲
- 打字角度：2.37° 和 5.33° 两段可调
- 工作环境：-10℃ 至 50℃

## 解释
R3 是一款面向日常办公与轻度游戏的 80% 配列键盘，紧凑布局节省桌面空间，同时保留方向键和功能键，兼顾效率与便携。相比全尺寸键盘，它更轻巧；相比 60% 键盘，它无需适应期。三模连接和长续航让它成为多设备用户的理想选择，无论是办公室、居家还是外出携带，都能轻松应对。
