# V4

## 产品定位
把耐用钢定位板、1000Hz 回报率和紧凑 60% 配列结合在一起的入门级机械键盘

## 目标用户
- 入门机械键盘用户：第一次尝试客制化，追求手感与性价比
- 预算有限的电竞玩家：需要高回报率与耐用轴体，但不想过度投入
- 桌面空间有限的办公用户：60% 紧凑配列，释放桌面空间
- DIY 爱好者：喜欢热插拔与改装，享受自己动手的乐趣

## 核心卖点
- 钢制定位板：提供坚实、一致的手感反馈，兼顾耐用性与稳定性
- 1000Hz 回报率：确保电竞场景下的低延迟响应，超越同级产品
- Tray Mount 结构：经典安装方式，兼顾手感一致性与改装的便利性

## 其他卖点
- 连接方式：Type-C 有线连接，附赠 Type-A 转接头
- 回报率：1000 Hz
- 配列：60% 紧凑布局
- 轴体：Keychron K Pro 轴（热插拔，兼容 5 脚/3 脚）
- 键帽：双色注塑 PBT，OSA 高度（OEM 高度、SA 外形），不透光
- 背光：South-facing RGB LED
- 卫星轴：螺丝固定 PCB 卫星轴
- 主控：超低功耗 ARM Cortex-M4 STM32L432（128KB Flash）
- 外壳：ABS 塑料
- 倾斜角度：3.5° / 7.98° / 11°（两段式脚撑）
- 系统兼容：支持 Mac/Win（需确认，规格未明示，但 Keychron 惯例）
- 工作环境：-10℃ 至 50℃

## 解释
V4 不是一把追求极致材质的旗舰，而是一把为入门用户和实用主义者打造的可靠工具。它把钢制定位板带来的扎实手感、1000Hz 的高回报率，以及 60% 的紧凑配列结合在一起，在有限的预算内提供了最核心的性能与体验。
相比同价位的竞品，V4 在回报率上明显领先（多数入门键盘为 125Hz 或 500Hz），并且钢定位板在耐用性和手感一致性上优于常见的铝或塑料。对于桌面空间有限的用户，60% 配列能释放大量空间，同时保留完整的键位功能（通过 FN 层）。
它适合第一次接触机械键盘、想体验客制化乐趣的用户，也适合需要快速响应、但不想为 RGB 或无线功能额外付费的电竞玩家。V4 是一把可以放心折腾、改装，且不会让你失望的入门佳品。
