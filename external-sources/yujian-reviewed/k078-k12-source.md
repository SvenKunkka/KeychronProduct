# K12

## 产品定位
把紧凑便携、多设备连接和持久续航结合在一起的60%配列无线机械键盘

## 目标用户
- 便携办公与移动办公用户
- 桌面空间有限的极简主义者
- 多设备办公用户（Mac/iOS/Windows/Android）
- 机械键盘入门与轻游戏玩家

## 核心卖点
- 60%紧凑配列，61键占桌面积减少40%，释放桌面空间
- 4000mAh大电池，关背光续航长达240小时，无线办公一周不充电
- 蓝牙5.1三设备连接，一键切换Mac/iOS/Windows/Android

## 其他卖点
- 连接方式：蓝牙5.1 + Type-C有线，无线模式90Hz、有线1000Hz回报率
- 配列：61键ANSI，12个多媒体键（Fn组合）
- 轴体：Gateron G Pro机械轴/Keychron光学轴/Keychron机械轴，热插拔版本可选
- 键帽：ABS材质，OEM高度
- 电池：4000mAh锂聚合物电池，RGB背光续航72小时，白背光68小时，关背光240小时
- 背光：18种灯效，4级可调RGB（非背光版除外）
- 系统：兼容Windows/Android/Mac/iOS
- 尺寸：塑壳版293×102mm，铝框版298×107mm，重约536g
- 声学：无填充（规格未提及，不写入）

## 解释
K12是一款为追求桌面整洁和移动办公效率的用户设计的60%配列键盘。它比传统全尺寸键盘节省约40%桌面空间，同时保留了完整的功能键（通过Fn组合实现），适合搭配笔记本使用或作为小桌面的主力键盘。
相比Keychron K系列其他型号，K12采用更紧凑的布局，牺牲了独立方向键和F区，但换来极小的体积和便携性。其4000mAh电池在同类产品中属于大容量，关背光续航240小时远超多数竞品（通常为100-200小时），蓝牙5.1支持三设备切换，适合多设备办公场景。
如果你需要一个不占地方、续航持久、能在手机、平板和电脑间无缝切换的键盘，K12是性价比极高的选择。
