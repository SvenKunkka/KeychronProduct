# V3 Max

## 产品定位
更稳定、更安静、更容易上手的 80% 配列三模机械键盘

## 目标用户
- 机械键盘发烧友
- 多设备办公用户
- 入门机械键盘用户
- 桌面整洁爱好者

## 核心卖点
- Gasket Mount 结构，搭配 PC 定位板，提供柔和一致的手感和更纯净的敲击音
- 三模连接（有线 / 2.4G / 蓝牙 5.1），4000mAh 大电池，关背光续航长达 190 小时
- 全键热插拔，兼容 3 针 / 5 针 MX 轴体，轻松定制手感

## 其他卖点
- 连接方式：有线 Type-C / 2.4G / 蓝牙 5.1
- 回报率：1000Hz（2.4G 和有线）/ 90Hz（蓝牙）
- 配列：80%
- 轴体：Gateron Jupiter（整装版）
- 键帽：Double-shot PBT，OSA 高度（OEM 高度、SA 形状）
- 电池：4000mAh，充电约 5 小时
- 续航：关背光约 190 小时，开 RGB 最低亮度约 100 小时
- 软件：支持 QMK / VIA（ARM Cortex-M4 主控）
- RGB：South-facing 灯位，支持多种灯效
- 声学填充：Gasket Mount 结构 + PC 定位板，优化敲击声音
- 系统兼容：Windows / macOS / Linux

## 解释
V3 Max 适合追求稳定无线体验和舒适手感的用户，无论是办公还是轻游戏，都能提供可靠表现。相比入门级产品，它升级了 Gasket 结构和 4000mAh 大电池，续航和手感都更出色；相比高端系列，它保持了亲民价格，是入门机械键盘的优选。它不是一把花哨的键盘，而是一个实用、耐用、可自定义的日常工具。
