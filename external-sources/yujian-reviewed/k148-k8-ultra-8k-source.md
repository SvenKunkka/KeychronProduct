# K8 Ultra 8K

## 产品定位
更稳妥的桌面主力键盘

## 目标用户
- 程序员 / 长时间文字工作者
- 办公与多设备切换用户
- 想要性能但不想牺牲日常体验的用户

## 核心卖点
- TKL配列

## 其他卖点
- 铝合金+塑胶机身
- 三模连接
- 4G 有线双 8K
- Win/Mac兼容
- LauncherAPP
- ZMK
- Per-Key RGB 和 Mix RGB
- Super 轴（规格书里写的，实物需要确认是否已经换成了Apex 轴）
- 南向灯
- 4000mAh电池
- 多层声学填充，优化声音和手感
