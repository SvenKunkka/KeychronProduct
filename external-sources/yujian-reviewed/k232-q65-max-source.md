# Q65 Max

## 产品定位
把铝合金质感、2.4GHz 无线性能和 65% 配列结合在一起的桌面型键盘

## 目标用户
- 机械键盘发烧友
- 高端电竞玩家
- 多设备办公用户
- 追求桌搭质感的用户

## 核心卖点
- 铝合金外壳，CNC 一体成型，质感与坚固兼备，为桌面增添高级感
- 2.4GHz 无线连接，1000Hz 回报率，媲美有线的低延迟体验，游戏办公两不误
- 4000mAh 大电池，关背光续航长达 180 小时，摆脱频繁充电烦恼

## 其他卖点
- 连接方式：2.4GHz / 蓝牙 5.1 / Type-C 有线，三模切换
- 回报率：1000Hz（2.4GHz / 有线），90Hz（蓝牙）
- 配列：65% 紧凑布局，节省桌面空间
- 轴体：Gateron Jupiter 轴，热插拔设计，兼容 3pin/5pin MX 轴
- 键帽：KSA 双色注塑 PBT 键帽，耐磨不打油
- 电池：4000mAh 锂电池，充电时间约 5 小时
- 软件：支持 QMK / VIA 改键，全键无冲
- RGB：22 种灯效，南向 RGB LED
- 声学：PCB 卫星轴，填充材料优化声音
- 系统：兼容 macOS / Windows / Linux

## 解释
Q65 Max 适合那些既追求键盘输入手感，又希望桌面整洁、无线自由的用户。它的 65% 配列在保留方向键和常用功能键的同时，大幅缩减桌面占用，搭配铝合金外壳，是桌搭的加分项。
相比纯有线键盘，Q65 Max 的 2.4GHz 无线模式提供了接近有线的性能，而蓝牙模式则方便多设备切换，办公效率更高。与普通塑料外壳键盘相比，铝合金机身不仅更耐用，也提升了整体质感。
如果你需要一把既能满足游戏低延迟需求，又能兼顾办公多设备连接，同时注重桌面美学的键盘，Q65 Max 是一个值得考虑的选择。
