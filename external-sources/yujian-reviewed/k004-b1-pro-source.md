# B1 Pro

## 产品定位
更轻、更薄、更便携的75%配列无线办公键盘

## 目标用户
- 追求轻薄便携的移动办公用户
- 多设备办公的Mac/iOS用户
- 桌面空间有限的入门机械键盘用户
- 需要静音办公的键盘用户

## 核心卖点
- 极致轻薄设计：前高仅5.2mm，后高14.5mm，打字角度3.2°，配合425g轻量机身，打造舒适的移动办公体验
- 多设备无缝切换：蓝牙5.2连接，支持macOS、iOS、Windows、Android、Linux全系统，轻松跨平台办公

## 其他卖点
- 连接方式：蓝牙5.2无线连接
- 配列：75%配列（77键），ANSI布局
- 电池：800mAh锂聚合物电池，充电时间约2.5小时
- 键帽：ABS材质键帽，无背光
- 多媒体键：12个多媒体按键
- 系统兼容：macOS、iOS、Windows、Android、Linux
- 工作环境：-10°C至50°C
- 产品尺寸：296 x 130 mm，重量425g

## 解释
B1 Pro不是一把游戏键盘，而是一把为移动办公和多设备用户打造的轻薄无线键盘。它没有背光、没有NKRO，但凭借极低的前高和轻巧的机身，成为MacBook用户的理想伴侣。相比传统机械键盘，B1 Pro更薄更轻，适合放入背包随身携带；相比薄膜键盘，它保留了机械手感，同时支持全系统多设备切换，是办公效率的提升工具。核心人群不是追求RGB和性能的电竞玩家，而是注重便携和实用性的办公用户。
