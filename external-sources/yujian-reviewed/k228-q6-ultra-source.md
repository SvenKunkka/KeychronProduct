# Q6 Ultra

## 产品定位
把电竞级性能、多设备连接和铝合金质感结合在一起的旗舰型键盘

## 目标用户
- 高端电竞玩家
- 机械键盘发烧友
- 多设备办公用户
- 桌面美学追求者

## 核心卖点
- 8000Hz 回报率：有线与 2.4GHz 模式下均支持 8000Hz，电竞级响应速度，操作更跟手
- CNC 铝合金外壳：全铝机身，重达 2238g，稳如磐石，敲击时纹丝不动
- 4000mAh 大电池：蓝牙关闭背光续航长达 660 小时，RGB 最低亮度也能用 200 小时

## 其他卖点
- 连接方式：2.4GHz / 蓝牙 5.3 / Type-C 有线，三模连接
- 回报率：有线与 2.4GHz 均 8000Hz，蓝牙 125Hz
- 配列：全尺寸
- 产品尺寸：137 × 446 mm；前高 20.6 mm，后高 31.09 mm；倾斜角 5.3°
- 轴体：Keychron Silk POM 轴，出厂润滑，顺滑耐用
- 键帽：PBT 材质（默认），支持热插拔
- 电池：4000mAh 锂聚合物电池
- 软件：支持 QMK / VIA，可自定义键位和灯效
- RGB：South-facing RGB LED，灯效均匀
- 声学填充：内置消音棉，敲击声更纯净
- 系统兼容：macOS / Windows / Linux 全兼容
- 其他：螺丝固定 PCB 卫星轴，稳定不晃

## 解释
Q6 Ultra 不是一把普通的全尺寸键盘，而是一台为电竞玩家和发烧友打造的桌面旗舰。它拥有 8000Hz 的回报率，在电竞场景中能提供极低的延迟，同时 CNC 铝合金机身带来扎实的质感和稳定性。
相比其他高端键盘，Q6 Ultra 在连接和续航上做到了极致：三模连接覆盖 2.4GHz、蓝牙和有线，4000mAh 电池让无线使用不再焦虑。而 660 小时的续航（关背光）更是让它在同类产品中脱颖而出。
核心用户不是普通办公族，而是追求极致性能和桌面质感的玩家。如果你需要一把能应对高强度游戏、又能无缝切换多设备、还能充当桌面艺术品的高端键盘，Q6 Ultra 就是答案。
