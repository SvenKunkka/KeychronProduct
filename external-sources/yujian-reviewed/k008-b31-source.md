# B31

## 产品定位
更轻便、更持久、更易上手的75%配列无线键盘

## 目标用户
- 办公用户
- 轻游戏玩家
- 多设备用户
- 预算有限的入门用户

## 核心卖点
- 超长续航：800mAh电池，无线使用时间高达320小时，免去频繁充电烦恼
- 三模连接：2.4GHz / 蓝牙5.2 / Type-C有线，多设备无缝切换
- 紧凑75%配列：保留方向键和功能键，节省桌面空间

## 其他卖点
- 连接方式：2.4GHz / Bluetooth 5.2 / Type-C有线
- 回报率：1000Hz（2.4GHz和有线）/ 125Hz（蓝牙）
- 配列：75%（82键）
- 轴体：不可热插拔，标配轴体
- 键帽：ABS材质，不可更换
- 电池：800mAh锂聚合物电池
- 软件：不支持QMK/VIA，无自定义软件
- 背光：无背光
- 系统兼容：Mac/Win双系统（需切换）
- 倾斜角度：5° / 6.5° / 9°
- 重量：520±10g
- 材质：ABS外壳

## 解释
B31是一款面向日常办公和轻度游戏用户的无线机械键盘，以超长续航和稳定连接为核心，适合不想频繁充电、需要多设备切换的办公场景。相比Keychron高端系列，B31舍弃了热插拔、背光和自定义软件，以更亲民的价格提供核心的机械手感与无线便利。对于预算有限、追求实用性的用户，B31是入门无线机械键盘的可靠选择。
