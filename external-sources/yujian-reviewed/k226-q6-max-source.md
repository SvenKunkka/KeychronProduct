# Q6 Max

## 产品定位
把全铝机身、三模连接和极致手感结合在一起的发烧级全尺寸键盘

## 目标用户
- 机械键盘发烧友
- 高端电竞玩家
- 桌面创作者 / Ultimate Desk Setup 用户
- 多设备办公用户

## 核心卖点
- 全铝机身，CNC 一体成型，重达 2184g，稳如泰山
- PC 定位板 + Gateron Jupiter 轴体，Q弹手感，声音纯粹
- 三模连接（2.4GHz / 蓝牙 / Type-C），1000Hz 回报率，游戏办公两不误

## 其他卖点
- 连接方式：2.4GHz / 蓝牙 / Type-C 有线
- 回报率：1000Hz（2.4GHz & 有线），90Hz（蓝牙）
- 配列：全尺寸
- 产品尺寸：137 × 446 mm
- 轴体：Gateron Jupiter 热插拔轴
- 卫星轴：螺丝固定 PCB 卫星轴
- 键帽：PBT 双色注塑（高度未指定）
- 电池：4000mAh 锂聚合物电池
- 续航：背光关闭最长 180 小时，RGB 最低亮度最长 100 小时
- 软件：QMK / VIA 支持（需确认）
- RGB：South-facing RGB LED
- 声学填充：多层消音结构（需确认）
- 系统兼容：macOS / Windows / Linux

## 解释
它不是一把普通的全尺寸键盘，而是将全铝 CNC 机身与 Gateron Jupiter 轴体、PC 定位板结合，带来稳重扎实的输入体验。相比塑料外壳的竞品，Q6 Max 的 2184g 重量和金属质感，更适合追求桌面高级感的用户。核心人群不是第一次买键盘的新手，而是对键盘材质、手感和连接性能都有要求的发烧友。
