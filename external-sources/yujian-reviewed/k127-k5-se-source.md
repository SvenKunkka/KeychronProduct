# K5 SE

## 产品定位
更薄、更轻、更高效的 104 键全尺寸矮轴机械键盘

## 目标用户
- 办公用户：需要全尺寸布局和数字小键盘，追求高效输入与多设备切换
- 轻游戏玩家：需要低延迟与RGB背光，但不想牺牲办公舒适度
- 桌面整洁爱好者：偏好无线连接与紧凑全尺寸设计，减少线缆杂乱
- Mac/iOS 用户：需要原生 Mac 键位与多系统兼容
- 入门机械键盘用户：想体验机械手感但预算有限，且偏好矮轴

## 核心卖点
- 矮轴设计：采用 Low Profile Gateron 机械轴或 Keychron 光轴，键程更短，响应更快，兼顾手感与便携
- 全尺寸配列：104 键完整布局，保留数字小键盘与 12 个多媒体键，办公效率直接拉满
- 双模连接：蓝牙 5.1 与 Type-C 有线，支持 3 台设备快速切换，多设备办公无缝衔接

## 其他卖点
- 连接方式：蓝牙 5.1 + Type-C 有线
- 回报率：有线 1000 Hz / 无线 90 Hz
- 配列：ANSI 104 键
- 轴体：Low Profile Gateron 机械轴 / Keychron 光轴
- 键帽：ABS 背光透光键帽 / PBT 非透光键帽
- 电池：2000mAh 锂聚合物电池
- 背光：18 种灯效，4 级 RGB 亮度可调
- 系统：Windows / Android / Mac / iOS 全兼容
- 材质：ABS 主体 + 铝合金边框，兼顾轻量与质感
- 重量：约 673g，便于携带
- 尺寸：435 x 120 mm，紧凑全尺寸
- 工作温度：-10 至 50℃

## 解释
K5 SE 适合需要全尺寸键盘但桌面空间有限的用户，矮轴设计让键盘更薄更轻，减少手腕压力，同时保留完整功能。相比传统全尺寸机械键盘，K5 SE 在保持输入效率的同时，更易携带和收纳，尤其适合多设备办公的 Mac/iOS 用户。其双模连接和 2000mAh 电池，满足日常无线使用需求，而 1000 Hz 有线回报率也能应对轻量游戏场景。
