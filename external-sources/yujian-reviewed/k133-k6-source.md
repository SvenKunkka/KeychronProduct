# K6

## 产品定位
更紧凑、更便携、更易上手的 68 键双模机械键盘

## 目标用户
- 办公+轻游戏用户
- 多设备办公用户
- 桌面空间有限的用户
- 初次尝试机械键盘的用户

## 核心卖点
- 68 键紧凑配列，节省桌面空间，同时保留方向键与常用功能键
- 蓝牙 5.1 与 Type-C 双模连接，最多可连接 3 台设备，无缝切换
- 4000mAh 大电池，蓝牙续航最长可达 570 小时

## 其他卖点
- 连接方式：蓝牙 5.1 + Type-C 有线
- 回报率：有线 1000Hz / 无线 90Hz
- 配列：ANSI 68 键
- 轴体：Keychron 机械轴
- 键帽：Double-Shot ABS，OEM 高度
- 电池：4000mAh 锂聚合物电池，充电约 3 小时
- 多媒体键：12 个
- 系统兼容：macOS / Windows
- 尺寸：313 x 104mm（塑壳版）/ 317 x 107mm（铝框版）
- 重量：约 530g

## 解释
K6 是一款紧凑型 68 键机械键盘，适合桌面空间有限但又需要完整功能的用户。它保留了方向键和常用功能键，同时通过蓝牙 5.1 实现多设备无缝切换，提升办公效率。相比全尺寸键盘，K6 更便携、更简洁，而 4000mAh 大电池和 570 小时续航，则让无线体验更加持久。
