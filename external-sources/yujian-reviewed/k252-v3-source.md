# V3

## 产品定位
更坚固、更稳、更容易定制的80%配列入门机械键盘

## 目标用户
- 预算有限的机械键盘入门用户
- 办公+轻游戏的日常用户
- 对键盘声音和手感有要求的DIY玩家

## 核心卖点
- 钢制定位板，提供坚实敲击手感和稳定支撑
- 支持5脚/3脚轴体热插拔，自由更换轴体，打造专属手感
- OSA高度双色注塑PBT键帽，兼顾舒适性与耐用性

## 其他卖点
- Type-C有线连接
- 1000Hz回报率
- 80%配列，节省桌面空间
- Keychron K Pro轴体（整装版）
- South-facing RGB LED，兼容侧刻键帽
- 螺丝固定PCB卫星轴，稳定不晃
- 支持QMK/VIA改键
- Mac/Win双系统兼容
- 三档倾斜角度（3.5°/7.26°/9.69°）
- 重量1120±10g，稳如泰山
- 工作温度-10℃至50℃

## 解释
V3是一款面向预算有限但追求品质的入门用户的机械键盘。它采用80%配列，保留完整功能键区，适合办公和轻游戏场景。钢制定位板提供了扎实的手感，相比普通入门键盘的塑料定位板，敲击更稳定，声音更清脆。热插拔轴座让你无需焊接即可更换轴体，轻松体验不同手感，是DIY玩家的入门佳选。
相比同价位的竞品，V3在细节上更用心：OSA高度键帽兼顾了原厂高度和SA球帽的舒适度，螺丝固定卫星轴减少了大键晃动，三档脚撑提供了更符合人体工学的倾斜角度。尽管是ABS外壳，但整体做工扎实，重量达到1.1kg，放在桌面上非常稳固。
如果你想要一把能陪伴你很久、可以慢慢折腾的键盘，V3是一个不会错的选择。
