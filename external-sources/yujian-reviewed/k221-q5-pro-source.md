# Q5 Pro

## 产品定位
把全铝机身、无线自由与 96% 配列结合在一起的旗舰型机械键盘

## 目标用户
- 追求极致桌面质感的桌面创作者
- 多设备办公与居家办公用户
- 机械键盘发烧友
- Mac/Windows 双系统用户

## 核心卖点
- 全 CNC 铝制机身，重达 2160g，稳如磐石
- 4000mAh 大电池，蓝牙续航长达 300 小时（关背光）
- KSA 双色注塑 PBT 键帽，手感细腻耐用

## 其他卖点
- 连接方式：蓝牙 5.1 / Type-C 有线
- 回报率：有线 1000 Hz，无线 90 Hz
- 配列：96% 布局，保留数字区
- 轴体：Keychron K Pro 热插拔轴，兼容 3 针/5 针 MX 轴
- 键帽：KSA 双色注塑 PBT，不透明
- 电池：4000mAh，续航最高 300 小时（关背光）
- 软件：支持 QMK/VIA，可自定义键位
- RGB：南向 RGB LED，支持多种灯效
- 声学：PC 定位板 + 螺丝卫星轴，声音纯净
- 系统：兼容 macOS/Windows/Linux

## 解释
Q5 Pro 不是一把普通的 96% 键盘，而是一台融合了全铝机身、无线自由与紧凑布局的桌面生产力工具。它适合那些每天在 Mac 与 Windows 之间切换、需要数字区又不想牺牲桌面空间的办公用户，也适合追求键盘质感和稳定性的机械键盘发烧友。相比同尺寸的塑料键盘，Q5 Pro 的 CNC 铝制机身提供了无与伦比的重量感和稳定性，而 4000mAh 电池带来的 300 小时续航，让你彻底告别电量焦虑。它是一把能陪你从办公室到家里的全能旗舰。
