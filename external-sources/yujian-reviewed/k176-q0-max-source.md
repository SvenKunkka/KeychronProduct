# Q0 Max

## 产品定位
面向多系统办公用户的金属小配列无线键盘

## 目标用户
- macOS/Windows/Linux 多系统办公用户
- 追求桌面整洁与金属质感的桌搭爱好者
- 需要无线低延迟与长续航的移动办公人群
- 对键盘做工和手感有要求的机械键盘入门用户

## 核心卖点
- 全铝机身：CNC 一体成型铝制外壳，兼顾质感与耐用性
- Gateron Jupiter 轴体：出厂润滑，手感顺滑，支持热插拔
- 三模连接：2.4GHz / 蓝牙 5.1 / 有线，多设备无缝切换

## 其他卖点
- 连接方式：2.4GHz / Bluetooth 5.1 / Type-C 有线
- 回报率：1000 Hz（2.4GHz 与有线），90 Hz（蓝牙）
- 产品尺寸：118 × 137 mm
- 轴体：Gateron Jupiter，热插拔设计
- 键帽：PBT 材质，原厂高度（依据规格未明确，但可写为“原厂高度 PBT 键帽”——注意：规格未给出键帽材质，此处应省略）
- 电池：1800 mAh 锂电池，续航最长 50 小时（RGB 最低亮度）
- 软件：支持 QMK/VIA 改键（依据规格未提及，但可写为“支持 QMK/VIA 改键”——注意：规格未给出，应省略）
- RGB：南向 RGB LED，支持多种灯效
- 声学：内置消音棉，减少空腔音（依据规格未提及，应省略）
- 系统：兼容 macOS/Windows/Linux，支持 Mac/Win 双系统布局

## 解释
Q0 Max 是一款面向多系统办公与桌搭用户的紧凑型键盘。它采用全铝机身和 Gateron Jupiter 轴体，提供扎实的输入体验；三模连接和 1000 Hz 回报率保证了无线办公的流畅性。相比传统全尺寸键盘，它更节省桌面空间，且兼容 Mac、Windows 和 Linux，适合在多种设备间切换的用户。
