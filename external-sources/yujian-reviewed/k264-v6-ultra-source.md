# V6 Ultra

## 产品定位
把电竞性能、多模连接和舒适手感结合在一起的桌面生产力工具

## 目标用户
- 高端电竞玩家
- 多设备办公用户
- 桌搭爱好者
- 追求极致性能的发烧友

## 核心卖点
- 8000 Hz 回报率，有线/2.4G 双模电竞级响应
- 4000 mAh 大电池，蓝牙续航高达 660 小时
- Silk POM 轴体，出厂润滑，顺滑耐用

## 其他卖点
- 连接方式：2.4 GHz / Bluetooth 5.3 / Type-C 有线
- 回报率：8000 Hz（有线/2.4G），125 Hz（蓝牙）
- 配列：100% 全尺寸
- 产品尺寸：149 × 447.9 mm；前高 24.7 mm，后高 31.2 mm
- 轴体：Keychron Silk POM Switch，热插拔
- 卫星轴：螺丝固定 PCB 卫星轴
- 键帽：PC 定位板，支持 Cherry 高度键帽（需另购）
- 电池：4000 mAh 锂聚合物电池
- 续航：背光关闭最高 660 小时，RGB 最低亮度 200 小时
- 背光：South-facing RGB LED
- 软件：支持 QMK/VIA 改键（需确认）
- 系统：macOS / Windows / Linux 全兼容
- 材质：塑料外壳，PC 定位板
- 倾角：4° / 9° / 11° 三档可调

## 解释
V6 Ultra 不是一把普通的塑料键盘，而是将电竞级 8000 Hz 回报率、三模连接和长效续航集于一身的全能选手。对于追求极致响应的电竞玩家，有线/2.4G 模式下的 8K 回报率能带来毫秒级的操作优势；对于多设备办公用户，蓝牙 5.3 可稳定连接多台设备，4000 mAh 电池在关闭背光时续航长达 660 小时，几乎忘记充电这件事。
相比同价位竞品，V6 Ultra 在性能上毫不妥协：8000 Hz 回报率通常只出现在高端磁轴键盘上，而 V6 Ultra 以塑料外壳和 PC 定位板实现了更亲民的定价，同时保留了热插拔、RGB 背光等客制化特性。它不是一把需要折腾的套件，而是开箱即用的高性能键盘，适合那些既想要电竞性能又不想牺牲日常办公体验的用户。
购买理由：如果你需要一把既能打游戏又能办公、续航持久且支持多设备的键盘，V6 Ultra 是当前市场上少有的全能之选。
