# K6 Pro

## 产品定位
更紧凑、更全能、更易上手的 65% 配列无线机械键盘

## 目标用户
- 追求便携与功能平衡的移动办公用户
- 桌面空间有限但需要完整键位功能的用户
- Mac/Windows 双系统切换的多设备用户
- 喜欢客制化调校的机械键盘入门玩家

## 核心卖点
- 65% 紧凑配列，保留方向键与常用功能键，桌面空间节省 40%
- 支持蓝牙 5.1 与 Type-C 有线双模连接，多设备无缝切换
- 4000mAh 大电池，关背光续航约 260 小时，开背光约 130 小时

## 其他卖点
- 连接方式：蓝牙 5.1 + Type-C 有线
- 回报率：有线 1000Hz / 无线 90Hz
- 配列：65% ANSI，68 键
- 轴体：South-facing，兼容客制化轴体
- 键帽：OSA 高度（OEM 球面角度）
- 电池：4000mAh 锂聚合物电池
- 软件：QMK/VIA 改键与宏定义
- 背光：22 种 RGB 灯效
- 声学：PCB 螺丝固定卫星轴，钢制定位板
- 系统：macOS/Windows/Linux 全兼容

## 解释
K6 Pro 适合那些想要紧凑键盘但又不愿牺牲功能键的用户。65% 配列在保留方向键和常用编辑键的同时，比全尺寸键盘节省大量桌面空间，尤其适合小桌面或移动办公场景。
相比 Keychron 的 60% 系列，K6 Pro 多出方向键和 F 区按键，实用性更强；而相比全尺寸键盘，它更便携、更节省空间。同时支持蓝牙 5.1 和有线双模，可同时连接多台设备，在 Mac 和 Windows 之间无缝切换，是跨平台用户的理想选择。
4000mAh 大电池提供了超长续航，关背光可达 260 小时，即使开启 RGB 也能坚持约 130 小时，彻底告别电量焦虑。QMK/VIA 支持让玩家可以自由定制键位和宏，满足个性化需求。
