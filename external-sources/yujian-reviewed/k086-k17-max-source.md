# K17 Max

## 产品定位
更薄、更轻、更易携带的96%配列低轴机械键盘

## 目标用户
- 追求桌面整洁与便携性的办公用户
- 需要多设备切换的跨平台工作者（macOS/Windows/Linux）
- 轻中度游戏玩家，偏好低延迟无线连接
- 对键盘手感有要求的入门机械键盘用户

## 核心卖点
- 96%配列全尺寸布局，保留数字区与功能键，节省桌面空间
- Gateron矮轴搭配矮键帽，触发快、手感清脆，兼顾办公与游戏
- 2.4G/蓝牙/有线三模连接，多设备无缝切换，跨平台兼容

## 其他卖点
- 连接方式：2.4GHz / 蓝牙5.1 / Type-C有线
- 回报率：蓝牙模式90Hz，有线/2.4G支持全键无冲
- 配列：ANSI 104键（96%）
- 轴体：Gateron矮轴（North-facing）
- 键帽：Low-profile double-shot PBT，耐磨不打油
- 电池：2000mAh，关背光续航约95小时，开RGB约50小时（最低亮度）
- 背光：22种RGB灯效，可自定义
- 系统：macOS / Windows / Linux 全兼容
- 尺寸：387x119mm，重750g，前高10.26mm，支持2°/4°/6°三段脚撑
- 工作温度：-10~50℃

## 解释
K17 Max 不是一把传统厚重的全尺寸键盘，而是一款将96%配列、矮轴与三模无线结合在一起的轻薄型机械键盘。它适合那些需要数字区但桌面空间有限的用户，比如财务、程序员或办公白领，同时也适合在办公室与家中多设备间切换的跨平台工作者。
相比传统104键键盘，K17 Max 节省了约4%的宽度，却保留了完整功能；相比普通机械键盘，矮轴与矮键帽让整体厚度大幅降低，前高仅10.26mm，打字更舒适，也更容易融入现代桌面美学。
核心人群不是追求极致客制化的发烧友，而是注重实用、便携与效率的日常用户。如果你想要一把既轻便又能胜任办公与轻游戏的键盘，K17 Max 是一个理想选择。
