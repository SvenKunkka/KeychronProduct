# S1

## 产品定位
把航空级铝材、紧凑75%配列和低剖面手感结合在一起的超薄便携键盘

## 目标用户
- 追求极致轻薄便携的移动办公用户
- 桌面空间有限但追求质感的桌搭爱好者
- 偏好低轴体手感与紧凑布局的机械键盘玩家
- 需要长时间码字的文字工作者
- 对键盘做工有高要求的品质用户

## 核心卖点
- 全CNC铝合金外壳，一体成型，坚固耐用且质感出众
- 前高仅7.8mm，极致超薄，配合3°/6°双角度脚垫，舒适贴合
- Gateron低剖面MX机械轴，兼顾机械手感与轻薄体验

## 其他卖点
- 连接方式：Type-C有线连接
- 回报率：1000Hz
- 配列：75%紧凑布局
- 轴体：Gateron Low Profile MX Mechanical，支持热插拔
- 键帽：Double-shot PBT低剖面键帽，不透明
- 背光：North-facing RGB LED
- 定位板：钢制定位板
- 主控：超低功耗ARM Cortex-M4 32-bit STM32L432
- 系统兼容：Mac/Win双系统（需确认）
- 配件：Type-C线材 + Type-A转Type-C适配器

## 解释
S1 是一款 75% 配列的低矮机械键盘，采用全 CNC 铝合金外壳，前高 7.8 mm。是否适合移动使用还取决于整机重量、包体空间和个人携带需求。
