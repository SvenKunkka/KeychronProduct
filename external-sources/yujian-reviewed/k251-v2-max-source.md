# V2 Max

## 产品定位
更实用、更耐用、更容易上手的 65% 配列无线机械键盘

## 目标用户
- 追求性价比的机械键盘入门用户
- 需要多设备切换的办公用户
- 喜欢紧凑布局但不想牺牲功能的桌面用户
- 轻度游戏玩家

## 核心卖点
- Gasket Mount 结构，手感软弹、声音纯粹
- 4000mAh 大电池，蓝牙续航长达 190 小时
- 支持 2.4G / 蓝牙 / 有线三模连接，全键无冲

## 其他卖点
- 1000 Hz 回报率（2.4G 和有线模式）/ 90 Hz（蓝牙模式）
- 65% 配列，紧凑布局，节省桌面空间
- Gateron Jupiter 轴体，热插拔兼容 3 针和 5 针 MX 轴
- OSA 高度双色注塑 PBT 键帽，耐磨不打油
- 4000 mAh 电池，关背光续航约 190 小时，开 RGB 约 100 小时（最低亮度）
- 支持 QMK 改键，可通过 VIA 软件自定义
- 南向 RGB 背光，支持多种灯效
- Gasket Mount 结构，内置消音填充，声音更纯净
- 兼容 Windows / macOS / Linux，附赠 Type-C 转 Type-A 适配器

## 解释
V2 Max 适合第一次接触机械键盘的用户，尤其是那些希望以较低成本获得完整无线体验和热插拔功能的玩家。它不像高端系列那样追求极致材质，但 Gasket 结构和 4000mAh 电池在同价位中非常突出。相比入门级产品，V2 Max 提供了更长的续航和更稳定的无线连接，是办公与轻度游戏的平衡之选。
