# K15 Pro

## 产品定位
把矮轴手感、无线自由和紧凑布局结合在一起的75%办公键盘

## 目标用户
- 追求轻薄便携的移动办公用户
- 桌面空间有限但需要完整功能键的用户
- 多设备切换的办公与轻游戏用户
- 对矮轴手感有偏好的机械键盘爱好者

## 核心卖点
- Gateron矮轴 + 低剖面双色PBT键帽，带来更短键程的快速触发与舒适敲击体验
- 蓝牙5.1三设备连接，2.4G/有线/蓝牙多模自由切换，办公效率翻倍
- 紧凑75%配列，保留方向键和F区，节省桌面空间的同时功能完整

## 其他卖点
- 连接方式：蓝牙5.1 + Type-C有线，支持双系统（macOS/Windows/Linux）
- 回报率：有线1000Hz，无线90Hz
- 配列：75% ANSI，89键，12个多媒体键
- 轴体：Gateron低剖面机械轴（North-facing）
- 键帽：低剖面双色PBT，耐磨不打油
- 电池：2000mAh锂电池，关背光续航约130小时，开RGB约65小时（最低亮度）
- 软件：支持QMK/VIA改键，可自定义RGB灯效
- RGB：22种灯效模式，支持自定义
- 声学：内部填充消音棉，减少空腔音
- 系统：兼容macOS/Windows/Linux，支持Mac/Win键位切换
- 尺寸：370×143mm，重量696g，前高11.5mm，后高16.5mm，提供3种打字角度（2.7°/3.9°/6.1°）

## 解释
K15 Pro是一款面向移动办公与桌面精简需求的矮轴机械键盘。它采用75%配列，在保留完整功能键的同时大幅缩减桌面占用，配合低剖面设计，即使长时间输入也能保持舒适姿态。相比传统机械键盘，矮轴触发更快、噪音更低，适合在办公室或咖啡厅等环境使用。其蓝牙5.1支持三设备快速切换，配合130小时超长续航，彻底告别电量焦虑。对于追求桌面整洁与高效输入的用户，K15 Pro是兼顾颜值与实力的理想选择。
