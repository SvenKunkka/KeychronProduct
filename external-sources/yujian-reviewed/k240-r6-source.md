# R6

## 产品定位
把全尺寸配列、三模连接和舒适手感结合在一起的办公型键盘

## 目标用户
- 办公+轻游戏用户
- 第一次购买机械键盘用户
- 多设备办公用户

## 核心卖点
- 全尺寸104键布局，配备12个多媒体键，办公效率直接拉满
- Keychron Super机械轴体，手感顺滑，适合长时间打字
- 三模连接（2.4G/蓝牙/有线），多设备无缝切换

## 其他卖点
- 连接方式：2.4 GHz / 蓝牙5.3 / Type-C有线
- 回报率：蓝牙模式125Hz，支持无线和有线全键无冲
- 键帽：双色注塑PBT，Cherry高度，耐磨不打油
- 电池：4000mAh，关背光续航约310小时
- 背光：22种RGB灯效，可自定义
- 系统兼容：macOS / Windows / Linux
- 打字角度：2.37º和5.33º，两段式脚撑
- 工作环境：-10至50℃

## 解释
R6是一款面向办公和轻游戏用户的全尺寸键盘，适合需要数字小键盘和高效输入的人群。它提供了全尺寸布局、多媒体按键和三模连接，兼顾了办公效率和桌面整洁。相比紧凑型键盘，R6在功能性和舒适性上更胜一筹，是办公桌面的可靠选择。
