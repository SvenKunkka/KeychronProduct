# K10 Pro

## 产品定位
面向多设备办公用户的 108 配列全尺寸蓝牙机械键盘

## 目标用户
- 桌面空间充裕、偏好全尺寸布局的办公用户
- 需要同时连接多台设备的 macOS/Windows 双系统用户
- 追求高性价比、一步到位入坑机械键盘的入门玩家

## 核心卖点
- 全尺寸 108 键 + 多媒体控制区，办公效率一步到位
- 双模连接（蓝牙 5.1 + Type-C），最多可连接 3 台设备
- 4000mAh 大电池，关背光续航约 260 小时

## 其他卖点
- 连接方式：蓝牙 5.1 和 Type-C 有线
- 回报率：有线 1000Hz，无线 90Hz
- 配列：108 键 ANSI 全尺寸
- 轴体：热插拔为可选配置；只有标注 Hot-Swappable 的配置支持热插拔，Black - Fully Assembled 非热插拔配置不支持。卫星轴结构也随配置不同。
- 键帽：OSA 高度（OEM 球面角度）
- 电池：4000mAh 锂聚合物电池，关背光续航约 260 小时，开 RGB 最低亮度约 130 小时
- 软件：支持 QMK/VIA 改键
- RGB：22 种灯效
- 系统：macOS/Windows/Linux 全兼容
- 其他：全键无冲，多媒体键 12 个，三档脚撑（3.5º/7º/10.5º）

## 解释
K10 Pro 是一款面向多设备办公用户的全尺寸机械键盘。它保留了完整的 108 键布局和多媒体控制区，适合需要频繁输入数字、使用功能键的办公场景，同时蓝牙 5.1 支持在电脑、平板、手机间快速切换，提升跨设备工作效率。
相比 Keychron 的 K 系列其他配列，K10 Pro 提供了更完整的键位和更大的操作空间，同时保留了热插拔、QMK/VIA 改键等客制化特性，让办公用户也能享受 DIY 的乐趣。4000mAh 大电池和优秀的续航表现，减少了频繁充电的烦恼，尤其适合长时间办公的用户。
如果你需要一把功能全面、续航持久、既能办公又能轻度游戏的键盘，K10 Pro 是一个高性价比的选择。
