# 81 Pro

## 产品定位
将全CNC铝合金机身、蓝牙5.1与4000mAh长续航结合在一起的81键紧凑型机械键盘

## 目标用户
- 追求桌面质感与精致工艺的机械键盘发烧友
- 需要多设备切换的办公用户（Mac/Windows/Linux）
- 注重无线续航与便携性的移动办公人群
- 喜欢自定义灯光与键帽的DIY玩家

## 核心卖点
- 全CNC铝合金机身：整块铝材精密加工，质感与强度兼备，搭配PC定位板，兼顾手感与声音表现
- 4000mAh大电池：关背光续航高达300小时，开RGB也能坚持100小时，无线使用告别电量焦虑
- 蓝牙5.1多设备连接：支持Mac/Windows/Linux/Android/iOS，一键切换，跨平台无缝办公

## 其他卖点
- 连接方式：蓝牙5.1 / Type-C有线
- 回报率：有线1000Hz，无线90Hz
- 配列：81键ANSI（US）全组装，紧凑布局
- 轴体：机械轴，兼容3针/5针MX轴体（Gateron、Cherry MX、Kailh等）
- 键帽：Double Shot PBT（非透光），耐磨不打油
- 卫星轴：螺丝式PCB卫星轴，稳定不晃动
- 背光：South-facing RGB LED，支持自定义灯效
- 热插拔：支持，方便更换轴体
- 主控：超低功耗ARM Cortex-M4 STM32L432（128KB Flash）
- 无冲：无线/有线均支持全键无冲
- 电池：4000mAh锂聚合物电池，关背光续航300小时，开RGB（最低亮度）100小时
- 系统兼容：Mac/Windows/Linux/Android/iOS
- 重量：1887±20g，稳固扎实
- 尺寸：33.83×15.05×4.73cm

## 解释
81 Pro适合那些既想要全尺寸键盘的输入效率，又希望节省桌面空间的用户。它采用81键紧凑布局，保留方向键和功能键，却比传统键盘更小巧。全CNC铝合金机身带来旗舰级的质感和耐用性，而4000mAh电池和蓝牙5.1则让无线办公变得自由无拘束。
相比普通塑料键盘，81 Pro在材质和做工上完胜，适合对桌面美学有要求的玩家；相比其他紧凑键盘，它的蓝牙多设备连接和长续航是核心优势，尤其适合多设备办公用户。
如果你想要一把既能代表品味、又能高效陪伴日常工作的键盘，81 Pro是值得考虑的选择。
