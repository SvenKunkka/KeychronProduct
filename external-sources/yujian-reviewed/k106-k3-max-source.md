# K3 Max

## 产品定位
把轻薄便携、三模连接和舒适打字角度结合在一起的 75% 配列矮轴键盘

## 目标用户
- 追求轻便与高效的多设备办公用户
- 需要紧凑布局但保留完整功能的桌面创作者
- macOS 与 Windows 双系统切换的混合办公人群
- 注重桌面整洁与低姿态美学的极简主义者

## 核心卖点
- 低剖面设计：11mm 前高，配合 2.5º/4.2º/6.5º 三档可调脚撑，兼顾轻薄与人体工学
- 三模连接：2.4GHz / 蓝牙 5.1 / Type-C 有线，支持多设备无缝切换，蓝牙模式 90Hz 回报率保障流畅输入
- 矮轴手感：Gateron 矮轴与 Keychron 矮轴可选，触发快速，适合长时间打字

## 其他卖点
- 连接方式：2.4GHz / 蓝牙 5.1 / Type-C 有线
- 回报率：蓝牙模式 90Hz
- 配列：84 键 (75%)，ANSI 布局
- 轴体：Gateron 矮轴 / Keychron 矮轴，North-facing 设计
- 键帽：低剖面双色注塑 PBT，耐磨不打油
- 电池：1550mAh 锂聚合物电池，续航持久
- 背光：22 种 RGB 灯效，支持自定义
- 系统兼容：macOS / Windows / Linux，支持 Mac/Win 双系统快捷键
- 多媒体键：12 个，方便快捷操作
- 无冲模式：无线/有线均支持全键无冲
- 材质：ABS + 铝合金边框，兼顾轻量与质感
- 尺寸：306 x 116 mm，重量 525g，便携性佳

## 解释
K3 Max 不是一款追求极致性能的电竞键盘，而是一款面向日常办公与创作场景的高效工具。它通过低剖面设计将键盘高度压缩至 11mm，配合三档脚撑，让长时间打字也能保持舒适姿态。相比传统机械键盘，它更轻薄、更便携，同时保留了 75% 配列的全部功能键，适合桌面空间有限但又不想妥协的用户。
与 Keychron 其他系列相比，K3 Max 的核心优势在于三模连接和低剖面设计。2.4GHz 模式提供低延迟体验，蓝牙 5.1 可同时连接多台设备，Type-C 有线则保证稳定供电和传输。对于需要在 Mac、Windows 甚至 Linux 之间切换的用户，它提供了无缝的跨平台支持。
购买 K3 Max 的理由很简单：如果你需要一把既能满足办公效率，又能融入桌面美学的键盘，它几乎是最佳选择。轻巧的机身、耐用的 PBT 键帽、丰富的 RGB 灯效，以及 22 种背光模式，让它在实用与个性之间找到了平衡。
