# V6

## 产品定位
更实用、更耐用、更容易上手的100%配列机械键盘

## 目标用户
- 办公用户：需要完整功能键区、数字小键盘，提升数据输入效率
- 桌面空间充足的家庭/办公室用户：偏好传统全尺寸布局，追求稳定耐用
- 初次接触机械键盘的用户：预算有限，希望以较低成本体验机械手感与RGB灯效

## 核心卖点
- 全尺寸布局：保留完整功能键区与数字小键盘，满足办公、数据录入等高效操作需求
- 钢制定位板：提供坚实稳定的敲击手感，增强键盘整体刚性，适合长时间高强度输入
- 热插拔轴座：支持3脚/5脚轴体，无需焊接即可自由更换轴体，轻松定制手感

## 其他卖点
- 连接方式：Type-C有线连接（附Type-A转接头）
- 回报率：1000 Hz
- 配列：100%全尺寸
- 轴体：Keychron K Pro（整装版）
- 键帽：双色注塑PBT，不透光，OSA高度（OEM高度，SA造型）
- 背光：南向RGB LED
- 主控：超低功耗ARM Cortex-M4 32位STM32L432（128KB Flash）
- 卫星轴：螺丝固定PCB卫星轴
- 安装结构：Tray Mount
- 外壳材质：ABS塑料
- 倾斜角度：3.5°/7.05°/9.52°
- 重量：1350±10g（整装版）
- 尺寸：447.85×140.55×26.83mm（不含键帽）
- 工作环境：-10℃至50℃

## 解释
V6是一款面向办公与入门用户的100%配列机械键盘。它保留了完整的数字小键盘和功能键区，适合需要频繁输入数据、使用快捷键的办公场景。相比紧凑配列，全尺寸布局无需适应期，即插即用。
与同价位竞品相比，V6采用钢制定位板，提供更扎实的敲击反馈，同时支持热插拔，方便用户后期自定义轴体。虽然采用ABS外壳，但整体做工扎实，重量达1.35kg，不易滑动。
核心人群不是追求便携的移动办公用户，而是桌面空间充足、注重实用性的家庭或办公室用户。如果你想要一把无需折腾、手感稳定、能应对日常所有输入需求的键盘，V6是一个高性价比的选择。
