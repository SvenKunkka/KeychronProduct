# B3 Pro

## 产品定位
更轻、更薄、更持久的 75% 配列无线办公键盘

## 目标用户
- 追求极致便携的移动办公用户
- 多设备切换的轻办公人群
- 注重桌面整洁与简约美学的用户

## 核心卖点
- 极致轻薄便携：前高仅 9.2mm、重量仅 410g，可轻松放入背包或公文包，随时随地高效办公。
- 超长续航：内置 800mAh 电池，单次充电可提供长达 300 小时的使用时间，减少频繁充电的烦恼。
- 多设备无缝切换：蓝牙 5.2 支持同时连接 3 台设备，一键切换 macOS/iOS/Windows/Android/Linux 系统，提升多设备办公效率。

## 其他卖点
- 连接方式：蓝牙 5.2 无线连接，支持 3 台设备快速切换
- 配列：75% 布局（79 键），ANSI 标准配列，节省桌面空间
- 键帽：ABS 键帽，手感细腻，经久耐用
- 电池：800mAh 锂电池，续航约 300 小时，充电时间约 2.5 小时
- 系统兼容：macOS、iOS、Windows、Android、Linux 全平台兼容
- 尺寸：296.8 x 127.5 mm，前高 9.2mm，后高 14.9mm，打字角度 2.8°
- 重量：410g，轻巧便携
- 工作温度：-10 至 50℃，适应多种环境

## 解释
B3 Pro 是一款 75% 配列的轻薄无线键盘，前高 9.2 mm，重量 410 g。官方资料给出的最长续航为 300 小时；实际续航取决于连接模式、背光和使用条件。
相比传统办公键盘，B3 Pro 在便携性、续航和多设备连接上做到了极致均衡。它没有背光、没有 NKRO，但正是这种取舍换来了更长的续航和更轻的机身，更贴合纯粹办公场景的需求。
核心用户并非追求性能的电竞玩家，而是每天需要携带键盘往返于办公室、咖啡厅或家中的移动办公者，以及希望在多设备间无缝切换的 macOS/iOS 用户。如果你需要一把“带了像没带”的键盘，B3 Pro 是理想之选。
