# K2 Max

## 产品定位
把 2.4G 低延迟、三模连接和 75% 配列结合在一起的办公游戏两用键盘

## 目标用户
- 多设备办公用户（Mac/Windows/Linux 三系统切换）
- 桌面空间有限但追求功能完整的 75% 配列用户
- 需要无线低延迟（2.4GHz）与长续航的居家/移动办公用户
- 偏好 RGB 灯效与个性化设置的入门机械键盘玩家

## 核心卖点
- 2.4GHz 无线连接，蓝牙 5.2 与 Type-C 有线三模切换，适配 macOS/Windows/Linux 全系统
- 4000mAh 大电池，关背光续航约 190 小时，减少充电焦虑
- Keychron Super 机械轴（South-facing），支持全键无冲（无线/有线均支持）

## 其他卖点
- 连接方式：2.4GHz / 蓝牙 5.2 / Type-C 有线
- 回报率：蓝牙模式 90Hz
- 配列：84 键（75%），ANSI 布局
- 轴体：Keychron Super 机械轴，South-facing 设计
- 键帽：Double-shot PBT 材质，OSA 高度（OEM 球形角）
- 电池：4000mAh 锂聚合物电池，关背光续航约 190 小时
- 软件：支持 QMK / VIA（需确认，但规格中未明确，故省略）
- RGB：22 种背光模式，可自定义
- 声学填充：规格未提及，省略
- 系统兼容：macOS / Windows / Linux
- 多媒体键：12 个
- 打字角度：5º / 9º / 12º 可调
- 边框材质：ABS 或 ABS+铝框（可选）
- 工作温度：-10℃ 至 50℃

## 解释
K2 Max 适合需要同时连接多台设备（Mac、PC、甚至 Linux 工作站）的用户，2.4GHz 模式提供低延迟体验，蓝牙 5.2 保证稳定连接，而 4000mAh 电池让无线使用不再频繁充电。
相比传统 75% 键盘，K2 Max 在无线性能上更突出，且支持全键无冲（无线/有线均支持），兼顾办公与游戏场景。
如果你想要一把小巧、无线、长续航且兼容全系统的键盘，K2 Max 是值得考虑的选择。
