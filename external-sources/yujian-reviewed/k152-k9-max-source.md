# K9 Max

## 产品定位
为便携办公用户打造的 60% 配列三模无线机械键盘

## 目标用户
- 便携办公用户
- 桌面空间有限的用户
- 多设备办公用户

## 核心卖点
- 超轻便携：仅 426g 重量与 287×97.5mm 紧凑尺寸，轻松放入通勤包
- 三模连接：2.4GHz / 蓝牙 5.2 / Type-C 有线，多设备无缝切换
- 低功耗长续航：1550mAh 电池，蓝牙模式 120Hz 回报率，兼顾续航与流畅

## 其他卖点
- 连接方式：2.4GHz / 蓝牙 5.2 / Type-C 有线
- 回报率：蓝牙模式 120Hz
- 配列：61 键 60% ANSI 布局
- 轴体：Keychron Milk POM 轴（North-facing）
- 键帽：Low-profile double-shot PBT 键帽
- 电池：1550mAh 可充电锂聚合物电池
- 软件：支持 QMK/VIA 改键（需确认）
- RGB：22 种 RGB 背光模式
- 声学填充：无（未提及）
- 系统兼容：macOS / Windows / Linux

## 解释
K9 Max 是为需要极致便携和高效多设备办公的用户设计的。它比传统 60% 键盘更轻更薄，适合桌面空间有限或经常移动办公的人群。相比自家其他系列，K9 Max 在保持紧凑配列的同时，通过三模连接和低功耗设计，提供了更灵活的使用场景。购买理由：如果你需要一把能轻松塞进背包、且能在电脑、平板、手机间无缝切换的键盘，K9 Max 是理想之选。
