# K10 Max

## 产品定位
面向多设备办公用户的 108 配列三模机械键盘

## 目标用户
- 追求高效办公与多设备切换的职场人士
- 偏好全尺寸配列与数字小键盘的实用主义者
- 兼顾办公与轻度游戏、注重性价比的用户
- Mac 与 Windows 双系统用户

## 核心卖点
- 三模连接（2.4GHz/蓝牙/有线），蓝牙模式回报率 90Hz
- 4000mAh 大电池，关背光续航约 190 小时，告别频繁充电
- 双系统原生支持（macOS/Win），配 12 个多媒体键，适配 Mac 键位

## 其他卖点
- 连接方式：2.4GHz / 蓝牙 5.1 / Type-C 有线
- 回报率：蓝牙模式 90Hz
- 配列：108 键（100%）ANSI 布局
- 轴体：Keychron Super / Apex 机械轴（South-facing）
- 键帽：双色注塑 PBT，OSA 高度（OEM 球形角度）
- 电池：4000mAh 锂聚合物电池，关背光续航约 190 小时
- 软件：支持 QMK / VIA 改键
- RGB：22 种背光模式
- 声学：多层消音填充
- 系统：macOS / Windows / Linux
- 其他：全键无冲（无线/有线），三档角度调节（3.43°/7.26°/10.06°）

## 解释
K10 Max 适合需要全尺寸键盘、同时使用 Mac 和 Windows 的办公用户，数字小键盘与 12 个多媒体键提升效率，三模连接和多设备切换让桌面更简洁。相比同价位竞品，它提供了 4000mAh 大电池和 190 小时超长续航，以及 2.4GHz 低延迟模式，兼顾办公与轻度游戏。如果你想要一把省心、耐用、功能齐全的全尺寸键盘，K10 Max 是性价比之选。
