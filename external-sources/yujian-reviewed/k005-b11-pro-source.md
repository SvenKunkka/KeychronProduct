# B11 Pro

## 产品定位
面向多设备办公用户的超轻便携型无线键盘

## 目标用户
- 追求极致便携的移动办公用户
- 需要多设备无缝切换的跨平台工作者
- 轻量级办公与日常输入用户

## 核心卖点
- 258g 超轻量机身，比多数平板电脑更轻，随身携带无负担
- 138 小时超长续航，实验室测试数据，告别频繁充电焦虑
- 蓝牙 / Type-C 有线连接，覆盖 Mac、Windows、iOS、Android、Linux 全平台

## 其他卖点
- 连接方式：Bluetooth / Type-C wired
- 电池：250mAh 可充电锂电池，续航 138 小时（实验室数据）
- 兼容系统：macOS / iOS / Windows / Android / Linux
- 主控芯片：RTL8762GKU，稳定低功耗
- 产品尺寸：392.6 x 143mm，紧凑设计节省桌面空间
- 外壳材质：ABS 工程塑料，轻量耐用
- 背光：无背光设计，专注续航与简洁

## 解释
它不是一把追求极致手感或炫酷灯效的键盘，而是一把为移动办公与多设备协作而生的工具。258g 的重量让它能轻松滑入背包，138 小时的续航让你在长途差旅中几乎忘记充电器，蓝牙与 Type-C 有线连接让它能适配手机、平板和笔记本。相比同类便携键盘，它在重量与续航上做到了极致平衡，特别适合经常出差、多设备办公、或桌面空间有限的用户。如果你需要一把能陪你走遍世界的可靠输入工具，B11 Pro 是值得考虑的选择。
