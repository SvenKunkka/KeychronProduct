# Q1（V2）

## 产品定位
把 CNC 铝制机身、75% 配列和 1000Hz 性能结合在一起的桌面级机械键盘

## 目标用户
- 机械键盘发烧友
- 高端电竞玩家
- 追求桌面质感的创作者
- Mac/Win 双系统用户

## 核心卖点
- 全 CNC 铝制机身，一体成型，质感与耐用性兼备
- 钢制定位板，提供扎实的敲击手感和声音反馈
- 75% 配列，紧凑布局兼顾功能与桌面空间

## 其他卖点
- Type-C 有线连接，稳定低延迟
- 1000Hz 回报率，电竞级响应
- Gateron G Pro / Phantom / Keychron K Pro 轴体可选
- 双色注塑键帽，不透明设计，耐磨持久
- 南向 RGB 背光，支持自定义灯效
- 全键热插拔，兼容 3 针/5 针 MX 轴体
- 螺丝式 PCB 卫星轴，减少晃动
- 支持 QMK / VIA 改键，Mac/Win 双系统
- 内置吸音棉，优化敲击声音
- 重量 1825g，稳固不易移动

## 解释
Q1（V2）适合追求键盘质感与性能的玩家，尤其是桌面创作者和电竞用户。全 CNC 铝制机身与钢制定位板带来扎实的触感和声音反馈，75% 配列在紧凑与功能之间取得平衡。相比同价位竞品，Q1（V2）在材质和做工上更具优势，同时支持 QMK/VIA 自定义，满足进阶玩家的个性化需求。
