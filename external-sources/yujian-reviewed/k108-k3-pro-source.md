# K3 Pro

## 产品定位
把矮轴手感、多设备连接和紧凑设计结合在一起的75%配列办公键盘

## 目标用户
- 追求便携与桌面简洁的移动办公用户
- 需要多设备无缝切换的Mac/Windows双系统用户
- 初次尝试矮轴机械键盘的轻量用户

## 核心卖点
- 矮轴设计：Gateron矮轴搭配低剖面PBT键帽，触发行程更短，长时间输入更省力
- 双模连接：蓝牙 5.1 最多连接 3 台设备，支持 Type-C 有线连接与模式切换
- 紧凑75%配列：保留方向键和F区，节省桌面空间，兼顾功能与便携

## 其他卖点
- 连接方式：蓝牙5.1 + Type-C有线
- 回报率：有线1000Hz / 无线90Hz
- 配列：84键ANSI 75%布局
- 轴体：Gateron矮轴（红/茶/青可选）
- 键帽：低剖面双色注塑PBT，耐磨不打油
- 电池：1550mAh锂聚合物电池，关背光续航约100小时，开RGB约50小时（最低亮度）
- 背光：22种RGB灯效，支持自定义
- 系统兼容：macOS/Windows/Linux，支持Mac/Win键位切换
- 无冲：有线/无线均支持全键无冲
- 角度调节：2.5°/4.2°/6.5°三档脚撑
- 尺寸重量：306×116mm，重525g，轻薄便携

## 解释
K3 Pro 是一款 75% 配列的矮轴键盘，前高约 11 mm。其便携性仍取决于整机尺寸、重量和用户的携带方式。
相比普通薄膜键盘，K3 Pro提供真正的机械手感，Gateron矮轴反馈清晰，打字更舒适；相比标准高度机械键盘，它无需手托即可长时间使用，对腕部更友好。蓝牙5.1支持三设备切换，配合Mac/Win双系统键位，是跨平台办公的得力助手。
如果你需要一把兼顾手感、便携和连接效率的键盘，K3 Pro是千元内少有的选择。
