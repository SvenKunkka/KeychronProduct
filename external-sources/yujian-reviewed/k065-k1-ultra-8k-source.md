# K1 Ultra 8K

## 产品定位
Keychron K1 Ultra 8K 是一款面向高效办公、桌搭审美和性能响应需求的三模低矮机械键盘。

## 目标用户
- 办公与多设备切换用户
- 桌搭与质感用户
- 客制化与进阶键盘用户
- 程序员、文字工作者、数据录入用户

## 核心卖点
- 铝材与木质侧边

## 其他卖点
- 三模连接
- Mac / Windows 双系统
- TKL布局加旋钮
- LSA 双色注塑 PBT 键帽
- POM 矮轴
- RGB 北向灯
- 热插拔
- 多层填充
- VIA 与 ZMK 相关能力
- 2600mAh 电池
