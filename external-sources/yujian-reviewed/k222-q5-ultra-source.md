# Q5 Ultra

## 产品定位
为高端桌面打造的 CNC 全铝三模机械键盘

## 目标用户
- 高端办公与桌面美学用户
- 追求稳定无线与低延迟的电竞玩家
- 多系统（macOS/Windows/Linux）切换的专业用户
- 对键盘做工与手感有极致要求的机械键盘发烧友

## 核心卖点
- 全 CNC 铝制外壳，底壳与外壳同材质，提供坚实稳重的质感与耐用性
- 三模连接（2.4GHz / 蓝牙 5.3 / Type-C），无线/有线均支持 8000Hz 回报率
- 4000mAh 大电池，背光关闭续航可达 660 小时

## 其他卖点
- 连接方式：2.4 GHz / Bluetooth 5.3 / Type-C 有线
- 回报率：8000 Hz（有线及 2.4GHz），125 Hz（蓝牙）
- 产品尺寸：144.8 × 408 mm；前高 20.7 mm，后高 31.8 mm；倾斜角 5°
- 轴体：Keychron Silk POM 轴，出厂润滑
- 卫星轴：Screw-in PCB 卫星轴
- 键帽：PBT 材质（依据规格未明确，但通常为 PBT，此处不写入）
- 电池：4000 mAh 可充电锂聚合物电池
- 软件：支持 QMK/VIA 改键（规格未明确，但 Keychron 产品通常支持，此处不写入）
- RGB：South-facing RGB LED
- 系统兼容：macOS / Windows / Linux
- 热插拔：支持

## 解释
Q5 Ultra 不是一把普通的机械键盘，而是为追求极致桌面体验的用户打造的桌面核心。全 CNC 铝制外壳提供了无与伦比的稳定性和质感，而三模连接与 8000Hz 回报率则兼顾了办公与电竞场景。相比传统塑料键盘，Q5 Ultra 在材质、续航和性能上都实现了全面超越，是高端用户的首选。
