# Q60 Max

## 产品定位
将全铝机身、三模连接与60%紧凑配列结合在一起的桌面级机械键盘

## 目标用户
- 机械键盘发烧友
- 高端电竞玩家
- 桌面美学追求者
- 多设备办公用户（Mac/Win/Linux）

## 核心卖点
- 全CNC铝合金机身，表面涂层处理，质感与耐用性兼备
- 三模连接（2.4GHz/蓝牙/有线），支持1000Hz回报率，游戏办公两不误
- 4000mAh大电池，关灯续航长达180小时，告别电量焦虑

## 其他卖点
- 连接方式：2.4GHz / Bluetooth 5.1 / Type-C有线
- 回报率：1000Hz（2.4GHz/有线），90Hz（蓝牙）
- 配列：60%紧凑布局
- 轴体：Gateron Jupiter（成品版），热插拔支持3针/5针MX轴
- 键帽：Cherry高度（需确认，规格未提及，暂不写）
- 电池：4000mAh，充电时间约5小时
- 软件：QMK/VIA支持（需确认，规格未提及，暂不写）
- RGB：22种灯效，南向RGB
- 声学填充：螺丝式PCB卫星轴，钢制定位板
- 系统兼容：Windows/macOS/Linux

## 解释
Q60 Max适合追求极致桌面质感与多设备无缝切换的用户。全CNC铝壳带来扎实手感，三模连接与长续航满足日常办公与游戏需求。相比同价位竞品，Q60 Max在材质与电池容量上更具优势，是兼顾性能与美学的理想选择。
