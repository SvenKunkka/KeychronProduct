# J2

## 产品定位
把机械手感、三模连接和紧凑布局结合在一起的75%配列键盘

## 目标用户
- 办公+轻游戏用户
- 多设备办公用户
- 入门机械键盘用户
- 便携/桌面空间有限用户

## 核心卖点
- 三模连接，2.4GHz/蓝牙/Type-C，多设备无缝切换
- 4000mAh大电池，关背光续航约300小时，告别电量焦虑
- 双键帽高度可选（Cherry/MDA），满足不同手感偏好

## 其他卖点
- 连接方式：2.4GHz / 蓝牙5.2 / Type-C有线
- 回报率：蓝牙模式125Hz，有线/2.4G模式支持全键无冲
- 配列：83键75% ANSI布局
- 轴体：机械轴（North-facing）
- 键帽：Double-shot PBT，Cherry/MDA高度可选
- 电池：4000mAh锂聚合物电池，关背光续航约300小时
- 软件：支持QMK/VIA改键（需确认，但规格未提及，此处不写）
- 背光：22种RGB灯效，可自定义
- 系统兼容：Windows / Mac / Linux
- 尺寸：332.3 x 139.92 mm，重量808g
- 打字角度：4.5º / 6.4º / 8.8º 可调
- 工作环境：-10℃ 至 50℃

## 解释
J2是一款面向日常办公和轻度游戏的紧凑型机械键盘。75%配列在保留F区和方向键的同时，大幅节省桌面空间，适合桌面有限或需要便携的用户。三模连接让它可以轻松在台式机、笔记本、平板之间切换，4000mAh电池和约300小时续航（关背光）更是免去了频繁充电的烦恼。
相比同价位竞品，J2提供了更完整的按键布局、双键帽高度选择以及多系统兼容，无论是Windows、Mac还是Linux用户都能即插即用。它不像高端磁轴或碳纤维键盘那样追求极致性能，而是以实用、稳定和易用为出发点，是入门机械键盘或办公升级的稳妥之选。
