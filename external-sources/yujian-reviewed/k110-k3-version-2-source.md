# K3 Version 2

## 产品定位

K3 Version 2 是一款 75% 超薄无线机械键盘。产品标题中的 “Ultra-slim” 表示超薄外形，不代表 Keychron Ultra 8K 产品系列。

## 核心卖点

- 84 键 75% 超薄配列。
- Bluetooth 5.1 与 Type-C 有线双模连接。
- 有线回报率 1000 Hz，无线回报率 90 Hz。
- 标准版提供低矮 Gateron 机械轴、Keychron Optical 光轴及热插拔选项。

## 审核边界

- 用户只说“K3”时，需先确认是 Version 2 还是 Version 3；两代续航、蓝牙版本、重量和轴体等字段不同。
- 用户询问配列或键帽时，还需确认 ANSI、ISO 或 JIS 地区版本。
- 本实体不得作为 K3 Ultra 8K 的别名。
