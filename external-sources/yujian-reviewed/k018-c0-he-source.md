# C0 HE

## 产品定位
面向游戏场景的 35 键单手机械键盘，采用磁轴和 8000 Hz 有线回报率。

## 核心卖点
- 35 键单手布局
- 8000 Hz 回报率，支持在 Launcher 中切换 1000 / 4000 / 8000 Hz
- 单键扫描率最高 256 kHz
- Keychron Ultra-fast Lime 磁轴
- 不可拆卸 USB-A 纯有线连接
