# K9 Pro

## 产品定位
为追求便携与多设备办公用户打造的60%矮轴无线机械键盘

## 目标用户
- 追求便携的移动办公用户
- 需要多设备切换的跨平台用户
- 桌面空间有限的轻办公用户
- 入门机械键盘用户

## 核心卖点
- 矮轴设计：Gateron low-profile机械轴，总高度仅7.6mm（前），兼顾机械手感与轻薄便携
- 多设备无缝切换：蓝牙5.1支持3设备连接，轻松切换手机、平板、电脑
- 全面系统兼容：macOS/Windows/Linux三系统原生支持，办公场景全覆盖

## 其他卖点
- 连接方式：蓝牙5.1 + Type-C有线双模
- 回报率：有线1000Hz / 无线90Hz
- 配列：60% ANSI，61键
- 轴体：Gateron low-profile机械轴，North-facing
- 键帽：Low-profile double-shot PBT，耐磨不打油
- 电池：1550mAh锂电池，关背光续航约100小时，开RGB约50小时（最低亮度）
- 背光：22种RGB灯效
- 无冲：无线/有线均支持全键无冲
- 多媒体键：12个
- 系统兼容：macOS/Windows/Linux
- 尺寸：287 x 97.5mm，重410g
- 打字角度：3.4°/5°/8°可调
- 工作温度：-10~50℃

## 解释
K9 Pro 不是一把传统厚重的机械键盘，而是一款将机械手感压缩进 7.6mm 高度的便携利器。它适合经常出差、需要在多个设备间切换的办公用户，也适合桌面空间有限但追求输入体验的入门玩家。相比普通薄膜键盘，K9 Pro 提供了更干脆的触感和全键无冲；相比标准机械键盘，它更轻、更薄、更易携带。蓝牙5.1的三设备切换和macOS/Windows/Linux的原生兼容，让它成为跨平台办公的理想选择。
