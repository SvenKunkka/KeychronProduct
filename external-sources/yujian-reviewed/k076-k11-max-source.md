# K11 Max

## 产品定位
把矮轴手感、三模连接和紧凑 65% 配列结合在一起的便携型键盘

## 目标用户
- 追求便携与桌面整洁的移动办公用户
- Mac/iPad 多设备切换的轻量用户
- 对机械手感有要求但偏好矮轴的低矮键盘爱好者

## 核心卖点
- Gateron 矮轴 + 低剖面双色 PBT 键帽，兼顾轻薄与机械手感
- 三模连接（2.4G/蓝牙/有线），蓝牙 5.1 支持多设备无缝切换
- 2000mAh 电池，关背光续航约 95 小时，满足一周以上重度使用

## 其他卖点
- 连接方式：2.4GHz / 蓝牙 5.1 / Type-C 有线
- 蓝牙回报率：90Hz
- 配列：68 键 65% ANSI 布局，支持全键无冲（无线/有线）
- 轴体：Gateron 矮轴（North-facing）
- 键帽：低剖面双色 PBT，耐磨不打油
- 电池：2000mAh 锂聚合物电池，关背光续航约 95 小时
- 背光：22 种 RGB 灯效，支持自定义
- 系统兼容：macOS / Windows / Linux
- 尺寸：346×115mm，重量 520g，前高 10.6mm，后高 15.6mm
- 打字角度：3.33°/4.7°/7.54° 三档可调
- 工作温度：-10~50℃

## 解释
K11 Max 采用 65% Alice 低矮配列，前高 10.6 mm，并使用 Gateron 矮轴与低剖面键帽。长时间使用是否舒适还取决于桌椅高度、腕部姿势和个人适应情况。
相比传统机械键盘，K11 Max 在保持机械手感的同时，通过矮轴和低剖面设计实现了更薄更轻的机身，便于放入背包或公文包。三模连接让它可以同时连接笔记本、平板和手机，蓝牙 5.1 支持快速切换，适合多设备办公场景。
K11 Max 的核心优势在于它平衡了便携性、手感和续航——2000mAh 电池在关背光下可提供约 95 小时使用时间，几乎可以做到一周一充，而 22 种 RGB 灯效又为喜欢桌搭的用户保留了可玩性。
