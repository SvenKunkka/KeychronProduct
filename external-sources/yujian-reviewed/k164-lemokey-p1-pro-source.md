# Lemokey P1 Pro 实体确认草稿（待审核）

> P1 Pro 与 P1 共用官方商品页，但官网正文、规格表、媒体标题和变体 SKU 前缀都明确区分两个版本。审核通过前不会进入产品事实账本或活动别名。

## 产品定位

75% 全 CNC 铝制、支持 2.4 GHz、Bluetooth 和 Type-C 有线连接的 QMK/VIA 无线客制化游戏键盘。

## 核心卖点

- 支持 2.4 GHz、Bluetooth 和 Type-C 有线三种连接方式。
- 2.4 GHz 与有线模式回报率为 1000 Hz，Bluetooth 模式为 90 Hz。
- 4000 mAh 电池；关背光最高 200 小时，RGB 最低亮度最高 100 小时。

## SKU 边界证据

- 当前 Keychron 商品 JSON 共 27 个变体，其中 15 个 P1 Pro 变体使用 `P1P-` 前缀，12 个 P1 变体使用 `P1-` 前缀。
- 本草稿不激活任何 SKU；SKU 必须在实体批准后通过独立受控批次加入。

## 审核注意

- 不得把 P1 的 1720 ± 50 g 写入 P1 Pro；P1 Pro 的 Fully Assembled 重量为 1650 ± 50 g。
- Fully Assembled 的重量、键帽和轴体结论不得扩展到 Barebone。
- 页面标题同时覆盖 P1/P1 Pro，必须以正文版本说明、规格表条件和 `P1P-` 变体前缀共同确认实体。
