# B36

## 产品定位
面向办公用户的全尺寸多模无线键盘

## 目标用户
- 办公用户
- 多设备用户
- 入门机械键盘用户
- 追求稳定无线连接的用户

## 核心卖点
- 三模连接：2.4GHz / 蓝牙5.2 / Type-C有线，适配多设备无缝切换
- 超长续航：800mAh电池，无线模式续航最高达320小时，减少充电频率
- 人体工学设计：三档倾斜角度（5°/6.5°/9°），满足不同打字姿势

## 其他卖点
- 100%全尺寸配列，108键，含数字小键盘，提升输入效率
- ABS键帽，耐用且手感细腻
- 1000Hz回报率（2.4GHz/有线模式），响应迅速
- 蓝牙5.2，连接稳定，兼容Mac/Win双系统
- 非背光设计，专注办公场景，节省电量
- Type-C接口，附赠Type-A转接头，兼容性强
- 工作温度范围-10℃至50℃，适应多种环境

## 解释
B36是一款为办公用户打造的全尺寸机械键盘。它采用100%配列，包含数字小键盘，适合财务、编程等需要频繁输入数字的用户。三模连接设计，让用户可以在台式机、笔记本、平板之间自由切换，提升工作效率。800mAh电池配合非背光设计，实现了最高320小时的超长续航，减少频繁充电的烦恼。相比同类产品，B36在续航和连接稳定性上表现突出，是追求实用与性价比的用户的理想选择。
