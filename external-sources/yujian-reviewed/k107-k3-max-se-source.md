# K3 Max SE

## 产品定位
带木质侧框的 75% 低矮型三模机械键盘。

## 核心卖点
- 75% 低矮配列，支持 QMK 与 Keychron Launcher
- 三模连接：2.4 GHz / Bluetooth 5.2 / Type-C 有线
- 2.4 GHz 与有线模式支持 1000 Hz 回报率

## 其他卖点
- 连接方式：2.4 GHz / Bluetooth 5.2 / Type-C 有线
- 配列：75%
- 回报率：1000 Hz（2.4 GHz 与有线）；125 Hz（Bluetooth）
