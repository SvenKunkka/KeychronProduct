# K11 Pro

## 产品定位
把低矮便携、无线自由和舒适打字结合在一起的65%配列办公键盘

## 目标用户
- 追求极致便携与桌面整洁的移动办公用户
- 需要多设备切换的跨平台工作者（Mac/Windows/Linux）
- 偏好低矮键帽与舒适打字角度的轻量级用户
- 对无线续航有较高要求的日常办公与轻游戏用户

## 核心卖点
- 超低矮机身与Gateron矮轴：前高仅10.6mm，搭配Gateron low-profile轴体，带来更接近笔记本的敲击手感，减少手腕压力
- 三种可调打字角度（3.33°/4.70°/7.54°）：通过折叠脚架实现个性化倾斜，适应不同坐姿与桌面高度
- 蓝牙5.1多设备连接：支持同时连接3台设备，一键切换，配合macOS/Windows/Linux全系统兼容，跨平台办公无缝衔接

## 其他卖点
- 连接方式：蓝牙5.1 + Type-C有线，双模连接
- 回报率：有线1000Hz / 无线90Hz
- 配列：65%布局（68键），ANSI标准
- 轴体：Gateron low-profile机械轴，North-facing（北向灯位）
- 键帽：Low-profile double-shot PBT，耐磨不打油
- 电池：2000mAh锂聚合物电池，关背光续航约130小时，开RGB（最低亮度）约65小时
- 背光：22种RGB灯效，支持自定义
- 无冲：有线/无线均支持全键无冲
- 多媒体键：12个，方便快捷操作
- 系统兼容：macOS/Windows/Linux，支持Win/Mac双系统键位
- 声学填充：内置消音棉，降低空腔音（根据规格未明确，但常见于Pro系列，此处不写）
- 尺寸重量：346×115mm，重510g，轻巧便携

## 解释
K11 Pro 不是一把传统厚重的机械键盘，而是将低矮机身与机械手感融合的便携利器。它适合每天背着电脑通勤、在咖啡厅或会议室临时办公的用户——前高仅10.6mm，几乎与笔记本键盘齐平，无需掌托即可舒适打字；三种角度调节则让不同身高和坐姿的人都能找到最放松的姿势。
相比自家K系列标准高度键盘，K11 Pro的矮轴设计大幅降低了手腕弯曲角度，对长时间码字的用户更友好；而相比普通薄膜键盘，它保留了机械轴的清脆反馈和PBT键帽的耐用性，同时蓝牙5.1与三设备切换功能让它在多设备办公场景中如鱼得水。
如果你追求桌面极简、经常移动办公，或者希望键盘与笔记本手感无缝衔接，K11 Pro是值得考虑的选择——它用2000mAh电池换来了130小时的无线续航，几乎告别电量焦虑。
