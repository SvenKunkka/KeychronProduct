# V10 Max

## 产品定位
面向多设备办公用户的75%配列三模无线机械键盘

## 目标用户
- 追求高性价比的入门机械键盘用户
- 多设备办公与居家办公用户
- 需要无线自由与长续航的轻中度游戏玩家
- 注重桌面整洁与RGB灯效的桌搭爱好者

## 核心卖点
- 三模连接，2.4G/蓝牙/有线自由切换，4000mAh大电池，关背光续航长达190小时
- Gasket Mount结构配合PC定位板，手感软弹，声音纯净
- 全键热插拔，兼容主流3针/5针MX轴体，轻松DIY

## 其他卖点
- 连接方式：蓝牙5.1 / 2.4GHz / USB-C有线
- 回报率：1000Hz（2.4G/有线），90Hz（蓝牙）
- 配列：75%布局，紧凑实用
- 轴体：Gateron Jupiter（整装版）
- 键帽：Double-shot PBT，OSA高度，不透光
- 电池：4000mAh，充电约5小时，关背光续航190小时，开RGB最低亮度100小时
- 软件：QMK/VIA改键（主控STM32F402）
- RGB：南向RGB背光
- 声学：Gasket Mount + PC定位板，填充优化
- 系统：Windows/macOS/Linux，支持Mac/Win双系统

## 解释
V10 Max是一款面向多设备办公与轻中度游戏用户的75%配列三模无线键盘。它解决了办公用户在多设备间切换的痛点，通过蓝牙5.1和2.4G无线，可同时连接多台设备，并拥有4000mAh大电池，关背光续航长达190小时，满足一周甚至更长时间的使用需求。
相比同价位产品，V10 Max在无线性能和续航上表现突出，同时Gasket Mount结构带来了更舒适的手感，而全键热插拔和QMK/VIA支持则让DIY玩家可以自由定制。它不是一把极致电竞键盘，也不是一把纯办公键盘，而是兼顾办公与游戏、无线与手感的均衡之选。
对于追求性价比、需要无线自由和长续航的用户，V10 Max是一个值得考虑的选择。
