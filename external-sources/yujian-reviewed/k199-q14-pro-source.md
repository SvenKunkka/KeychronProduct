# Q14 Pro

## 产品定位
为高效办公打造的96%配列全铝机械键盘

## 目标用户
- 追求桌面质感与全铝机身的高级办公用户
- 需要全尺寸布局与数字小键盘的财务/数据录入人员
- 多设备办公用户（Mac/Windows/Linux 三系统切换）
- 长时间打字、注重手感和稳定性的重度文字工作者

## 核心卖点
- 全CNC阳极氧化铝机身，质感与稳重并存
- 96%配列保留数字小键盘，办公效率最大化
- QMK/VIA 全键自定义，专属你的工作流

## 其他卖点
- 连接方式：蓝牙5.1 / Type-C 有线，支持三系统（macOS/Windows/Linux）
- 回报率：1000Hz（有线）/ 90Hz（无线）
- 配列：96%
- 轴体：Keychron K Pro 热插拔，兼容 3针/5针 MX 轴
- 键帽：KSA 双色注塑 PBT 键帽，不透明，耐磨不打油
- 电池：4000mAh，关背光续航约 300 小时，开 RGB 最低亮度约 100 小时
- 软件：QMK / VIA 全键编程，支持宏和快捷键
- RGB：南向 RGB LED，支持多种灯效
- 声学填充：PC 定位板 + 螺丝卫星轴，敲击声纯净
- 系统兼容：macOS / Windows / Linux

## 解释
Q14 Pro 不是一把简单的全尺寸键盘，而是为办公效率与桌面质感而生的生产力工具。96% 配列在保留数字小键盘的同时，比传统全尺寸更紧凑，节省桌面空间。全铝机身带来沉稳的重量与质感，适合长时间打字。相比普通办公键盘，Q14 Pro 支持 QMK/VIA 全键自定义，可以按你的习惯重新布局，配合 4000mAh 大电池和蓝牙 5.1，无线办公无忧。
