# V8

## 产品定位
更紧凑、更顺手、更容易上手的65%配列入门机械键盘

## 目标用户
- 入门机械键盘用户
- 桌面空间有限的办公用户
- 追求性价比的DIY玩家

## 核心卖点
- 65% 配列，紧凑布局，保留方向键与功能区，节省桌面空间
- 钢制定位板 + Tray Mount 结构，提供扎实稳定的敲击手感

## 其他卖点
- 有线连接：Type-C
- 回报率：1000 Hz
- 配列：65%
- 轴体：Keychron K Pro，支持热插拔（5 pin / 3 pin）
- 键帽：双色注塑 PBT，OSA 高度（OEM 高度，SA 形状），不透光
- 背光：南向 RGB LED
- 卫星轴：螺丝固定 PCB 卫星轴
- 主控：超低功耗 ARM Cortex-M4 32-bit STM32L432（128KB Flash）
- 兼容系统：Mac / Win 双系统
- 角度调节：3.5° / 7.99° / 11°
- 重量：945 ± 10 g（整装版）

## 解释
V8 是一款为入门用户和桌面空间有限的用户打造的 65% 配列有线机械键盘。它保留了方向键和常用功能键，在紧凑布局与实用性之间取得平衡，适合办公和轻游戏场景。
相比 Keychron 其他高端系列，V8 采用 ABS 塑料外壳和钢制定位板，成本更亲民，同时保留了热插拔轴座、南向 RGB 和 QMK 支持（基于 ARM 主控），让入门用户也能享受 DIY 的乐趣。
如果你想要一把不占地方、手感扎实、又能在 Mac 和 Windows 之间无缝切换的键盘，V8 是一个高性价比的选择。
