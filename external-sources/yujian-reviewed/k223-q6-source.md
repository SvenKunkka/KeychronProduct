# Q6

## 产品定位
把全尺寸配列、CNC 铝制机身和 QMK 可编程性结合在一起的桌面旗舰键盘

## 目标用户
- 办公室白领 / 程序员
- 桌面整洁控 / 极简主义者
- 机械键盘发烧友
- Mac 用户 / 多设备办公者

## 核心卖点
- 全 CNC 铝制机身，一体成型，重达 2420g，稳如磐石
- QMK/VIA 全键可编程，支持 Mac/Win 双系统，办公效率翻倍
- 1000Hz 回报率，电竞级响应，办公游戏两不误

## 其他卖点
- Type-C 有线连接
- 1000Hz 回报率
- 100% 配列（全尺寸）
- Gateron G Pro 轴体（热插拔，支持 5 针/3 针）
- OSA 高度双色注塑 PBT 键帽，不透明
- 南向 RGB 背光
- 螺丝式 PCB 卫星轴
- 多层消音填充
- Mac/Win 双系统兼容，附赠 Type-A 转 Type-C 转接头
- 工作温度 -10℃ 至 50℃

## 解释
Q6 不是一把普通的全尺寸键盘，而是一块由整块铝锭 CNC 加工而成的桌面基石。它适合那些需要完整数字键区、又追求极致稳定性和质感的用户——无论是财务、程序员还是桌面收纳控。相比塑料壳的竞品，Q6 的 2420g 重量带来的是纹丝不动的输入体验，而 QMK 的加持则让每个按键都听你指挥。如果你想要一把一步到位的全尺寸键盘，Q6 就是那个答案。
