# V10 Ultra

## 产品定位
把8K回报率、三模连接和4000mAh长续航结合在一起的无线性能键盘

## 目标用户
- 追求极致无线性能的电竞玩家
- 需要多设备无缝切换的办公用户
- 注重桌面整洁与无线自由的极简主义者
- 对续航有高要求的移动办公人群

## 核心卖点
- 三模连接：2.4GHz / 蓝牙5.3 / Type-C有线，无线与有线场景无缝切换
- 8000Hz回报率（有线及2.4GHz），电竞级响应速度，蓝牙模式下也有125Hz
- 4000mAh大电池，背光关闭续航高达660小时，RGB最低亮度下200小时

## 其他卖点
- 连接方式：2.4GHz / 蓝牙5.3 / Type-C有线
- 回报率：8000Hz（有线及2.4GHz），125Hz（蓝牙）
- 产品尺寸：162.2 × 389.6 mm
- 轴体：Keychron Silk POM 轴，热插拔支持
- 键帽：PC定位板，South-facing RGB
- 电池：4000mAh锂聚合物电池
- 软件：QMK/VIA支持（需确认）
- RGB：南向RGB LED
- 声学：PC定位板，螺丝卫星轴
- 系统：macOS/Windows/Linux

## 解释
V10 Ultra 不是一把普通的无线键盘，而是将顶级有线性能（8K回报率）与无线便利（三模连接）结合在一起的性能利器。对于电竞玩家，2.4GHz下8K回报率确保极低延迟，而蓝牙模式又能轻松连接办公设备。4000mAh电池和660小时续航，让移动办公用户告别电量焦虑。相比其他无线键盘，V10 Ultra在无线性能上毫不妥协，同时提供了多设备兼容和超长续航，是追求极致无线体验用户的理想之选。
