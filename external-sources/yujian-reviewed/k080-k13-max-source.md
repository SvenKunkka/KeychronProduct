# K13 Max

## 产品定位
更轻薄、更便携、更易上手的80%配列矮轴机械键盘

## 目标用户
- 追求极致便携与桌面整洁的移动办公用户
- 需要多设备无缝切换的Mac/Windows双系统用户
- 对键盘手感与品质有要求的轻中度游戏玩家
- 初次尝试矮轴键盘的机械键盘入门用户

## 核心卖点
- 矮轴设计：Gateron矮轴搭配低剖面PBT键帽，总高度仅14.7mm，兼顾机械手感与轻薄便携
- 三模连接：2.4GHz/蓝牙5.1/Type-C有线，支持同时连接多设备，跨平台无缝切换
- 全键无冲：无线与有线模式下均支持全键无冲，游戏操作精准无误

## 其他卖点
- 连接方式：2.4GHz / 蓝牙5.1 / Type-C有线
- 回报率：蓝牙模式90Hz
- 配列：80% ANSI布局，90键
- 轴体：Gateron矮轴（North-facing）
- 键帽：低剖面双色注塑PBT
- 电池：2000mAh锂聚合物电池
- 续航：关背光约95小时，开RGB约50小时（最低亮度）
- 软件：支持QMK/VIA改键（需确认，但规格未列出，故不写入）
- RGB：22种RGB背光模式
- 系统兼容：macOS / Windows / Linux
- 打字角度：3.37º / 4.2º / 6.7º
- 工作环境：-10℃至50℃

## 解释
K13 Max是一款面向追求便携与多设备办公的用户打造的矮轴机械键盘。它比传统机械键盘更薄更轻（600g），同时保留了机械手感，适合经常携带键盘外出或桌面空间有限的用户。相比Keychron的常规高度键盘，K13 Max的矮轴设计降低了打字高度，减少了手腕压力，同时支持三模连接，让用户在台式机、笔记本、平板间自由切换。它不是一款极致性能的电竞键盘，但凭借全键无冲和稳定的无线连接，足以应对主流游戏。如果你想要一把既能提升办公效率，又能兼顾轻游戏的键盘，K13 Max是不错的选择。
