# Q6 Pro

## 产品定位
把全尺寸配列、全铝机身与无线体验结合在一起的旗舰级机械键盘

## 目标用户
- 追求全尺寸布局与顶级质感的机械键盘发烧友
- 需要数字小键盘的办公用户与数据录入人员
- 注重桌面美学与金属工艺的桌搭爱好者
- Mac/Windows 双系统切换的多设备用户

## 核心卖点
- 全 CNC 铝制机身：整块铝材精密加工，重达 2160g，稳固扎实，带来极致金属质感与耐用性
- 100% 全尺寸配列：保留完整数字区与功能键，兼顾办公效率与桌面气场
- 4000mAh 大电池 + 蓝牙 5.1：关背光续航长达 300 小时，无线办公无忧

## 其他卖点
- 连接方式：蓝牙 5.1 / Type-C 有线
- 回报率：1000Hz（有线）/ 90Hz（无线）
- 配列：100% 全尺寸
- 轴体：Keychron K Pro 热插拔轴，兼容 3 针/5 针 MX 轴体（如 Gateron、Cherry MX、Kailh）
- 键帽：KSA 双色注塑 PBT 键帽，非透光
- 电池：4000mAh 锂聚合物电池，关背光续航约 300 小时，开 RGB 最低亮度约 100 小时
- 软件：支持 QMK/VIA 改键（需有线连接）
- RGB：南向 RGB LED，支持多种灯效
- 声学：PC 定位板 + 螺丝固定 PCB 卫星轴，填充结构优化声音
- 系统兼容：macOS / Windows / Linux

## 解释
Q6 Pro 不是一把普通的全尺寸键盘，而是一把将全铝机身、全尺寸配列与无线便利融为一体的旗舰作品。它适合那些需要完整数字区、又对桌面质感和输入体验有极高要求的用户——无论是程序员、财务人员还是内容创作者，都能在 100% 配列中找到效率与舒适的平衡。
相比市面上常见的塑料全尺寸键盘，Q6 Pro 的 CNC 铝制外壳提供了无与伦比的稳固感和质感，同时 4000mAh 电池与蓝牙 5.1 让无线办公不再频繁充电。它既是一把生产力工具，也是一件桌面艺术品。
