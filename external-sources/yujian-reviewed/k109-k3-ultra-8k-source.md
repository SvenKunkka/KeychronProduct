# K3 Ultra 8K

## 产品定位
75% 低矮型三模 8K 机械键盘。

## 核心卖点
- 75% 低矮配列，支持 ZMK 与 Keychron Launcher
- 三模连接：2.4 GHz / Bluetooth 5.2 / Type-C 有线
- 有线与 2.4 GHz 模式支持 8000 Hz 回报率

## 其他卖点
- 连接方式：2.4 GHz / Bluetooth 5.2 / Type-C 有线
- 配列：75%
- 回报率：8000 Hz（有线与 2.4 GHz）；125 Hz（Bluetooth）
