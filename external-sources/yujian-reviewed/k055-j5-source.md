# J5

## 产品定位
支持 QMK 与 Keychron Launcher 的 100% 全尺寸三模机械键盘。

## 核心卖点
- 108 键 100% 全尺寸配列
- 2.4 GHz、Bluetooth 5.2 与 Type-C 有线三模连接
- 2.4 GHz 与有线模式 1000 Hz 回报率
- 提供热插拔和非热插拔版本
