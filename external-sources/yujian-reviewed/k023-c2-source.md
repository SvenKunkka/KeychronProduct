# C2

## 产品定位
为办公和入门用户打造的全尺寸有线机械键盘

## 目标用户
- 办公用户：需要全尺寸布局、数字小键盘和多媒体键，提升工作效率
- 入门机械键盘用户：第一次尝试机械键盘，追求可靠性和性价比
- 多系统用户：在 Windows 和 macOS 之间切换，需要兼容性好的键盘

## 核心卖点
- 全尺寸 104 键布局，配备 12 个多媒体键，办公效率直接拉满
- 支持 Windows/Android/Mac/iOS 全系统，即插即用，无需额外设置
- RGB 背光可调 4 级亮度，18 种灯效，桌面氛围随心切换

## 其他卖点
- Type-C 有线连接，1000Hz 回报率
- ANSI 配列，OEM 高度键帽，双色注塑 ABS 键帽（背光版）
- Gateron G Pro 机械轴体或 Keychron 自研轴体，可选热插拔版本
- 重量约 829g，尺寸 435.6 x 130mm，工作温度 -10 至 50℃
- 兼容 macOS 和 Windows 系统

## 解释
C2 是一款面向办公和入门用户的 104 键全尺寸键盘。它提供了完整的数字小键盘和 12 个多媒体键，适合需要频繁输入数字和操作媒体的办公场景。相比紧凑型键盘，C2 无需适应期，上手即用。
与自家高端系列（如 Carbon）相比，C2 采用 ABS 外壳和双色注塑键帽，更注重实用性和性价比，是机械键盘入门和办公升级的理想选择。
