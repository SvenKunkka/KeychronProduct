# K7

## 产品定位
更轻巧、更便携、更易上手的 68 键矮轴机械键盘

## 目标用户
- 轻办公与便携出行用户
- 桌面空间有限的用户
- 入门机械键盘用户
- 多设备办公用户

## 核心卖点
- 矮轴设计，紧凑便携，轻至 348.7g
- 双模连接，蓝牙 5.1 稳定高效
- 热插拔轴体，支持 Gateron 与 Keychron 光学矮轴

## 其他卖点
- 连接方式：蓝牙 5.1 + Type-C 有线
- 配列：68 键 ANSI 布局
- 轴体：Low-profile Gateron 机械轴 / Low-profile Keychron 光学轴
- 键帽：ABS 材质
- 电池：1550mAh 锂聚合物电池
- 续航：蓝牙模式最低亮度下约 34 小时（白光版与 RGB 版）
- 软件：未标注
- 背光：18 种灯效，4 级可调
- 系统兼容：macOS / Windows
- 尺寸重量：307 x 97.5mm，约 348.7g

## 解释
K7 适合需要频繁携带键盘的移动办公用户，或桌面空间有限的入门玩家。相比传统全尺寸键盘，它的 68 键布局和矮轴设计显著减少占用空间，同时保持完整功能。与 Keychron 其他产品线相比，K7 更强调便携性和易用性，是追求轻量化桌面的理想选择。
