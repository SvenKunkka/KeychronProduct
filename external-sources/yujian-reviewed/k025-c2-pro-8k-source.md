# C2 Pro 8K

## 产品定位
为电竞玩家打造的8K回报率全尺寸有线机械键盘

## 目标用户
- 电竞玩家与FPS爱好者：追求8K回报率的极限响应速度，在竞技游戏中抢占先机
- 办公效率用户：100%配列保留数字键盘，输入数据、记账等场景效率更高
- 桌面整洁主义者：Type-C有线连接+附赠转接头，简化桌面，避免无线延迟与充电烦恼
- 机械键盘入门用户：即插即用，无需驱动，兼容Mac/Win，上手零门槛

## 核心卖点
- 8K回报率：8000Hz轮询率，延迟低至0.125ms，是传统键盘的8倍速度，电竞级响应
- Keychron Super Switch / Apex Switch：自研轴体，出厂润滑，手感顺滑，寿命持久
- 100%配列+Tray Mount：全键位布局，保留数字区，办公游戏两不误；Tray Mount结构提供一致且稳定的敲击手感

## 其他卖点
- 连接方式：Type-C有线连接，附Type-A转接头
- 回报率：8000Hz
- 配列：100%全尺寸
- 轴体：Keychron Super Switch / Apex Switch，支持热插拔（5针/3针）
- 键帽：OSA高度双色注塑PBT键帽，耐磨不打油
- 背光：South-facing RGB LED，灯效酷炫
- 主控：ARM Cortex-M4 32-bit AT32F405
- 卫星轴：钢板卫星轴，稳定不晃
- 兼容性：支持Mac/Win双系统
- 工作环境：-10℃至50℃

## 解释
C2 Pro 8K不是一把普通的全尺寸键盘，而是将8K电竞级响应速度与全尺寸办公实用性结合的产物。对于追求极致反应的电竞玩家，8K回报率带来的低延迟是实实在在的优势；而对于需要数字键盘的办公用户，100%配列和Tray Mount结构则提供了高效输入与舒适手感。相比Keychron自家其他系列，C2 Pro 8K更聚焦于“速度”与“实用”的平衡，是那些不想在办公与游戏之间切换键盘的用户的理想选择。
