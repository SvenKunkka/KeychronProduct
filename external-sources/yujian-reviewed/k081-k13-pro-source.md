# K13 Pro

## 产品定位
把低剖面设计、多设备无线连接和紧凑 80% 配列结合在一起的办公型键盘

## 目标用户
- 多设备办公用户（需要在 Mac、Windows 和 Linux 设备间无缝切换）
- 桌面空间有限的用户（80% 配列，紧凑设计）
- 追求低剖面手感与便携性的机械键盘用户
- 办公+轻度游戏用户（无线 90Hz、有线 1000Hz 回报率）

## 核心卖点
- 低剖面设计：搭配 Gateron 矮轴与矮键帽，整体高度仅 7.72mm（前缘），打字更舒适、更符合人体工学
- 三系统兼容：原生支持 macOS、Windows 和 Linux，蓝牙 5.1 可同时连接多设备并快速切换
- 紧凑 80% 配列：保留 90 键（含 12 个多媒体键），节省桌面空间，功能不缩水

## 其他卖点
- 连接方式：蓝牙 5.1 和 Type-C 有线双模
- 回报率：有线 1000Hz，无线 90Hz
- 配列：ANSI 布局，90 键（80%）
- 轴体：Gateron 矮轴（北向灯位）
- 键帽：低剖面双色注塑 PBT 键帽，耐磨不打油
- 电池：2000mAh 锂电池，关背光续航约 130 小时，开 RGB（最低亮度）约 65 小时
- 背光：22 种 RGB 灯效，支持自定义
- 无冲：有线和无线均支持全键无冲
- 材质：ABS 底壳 + 铝合金上框，兼顾轻量与质感
- 系统：macOS/Windows/Linux 全兼容
- 尺寸：346 x 118.5 mm，重 580g，便携紧凑
- 倾角：3.37º / 4.2º / 6.7º 三档调节
- 工作温度：-10℃ 至 50℃

## 解释
K13 Pro 适合那些需要在 Mac、Windows 和 Linux 设备间频繁切换的办公用户。它通过蓝牙 5.1 实现多设备连接，配合低剖面设计，让长时间打字更轻松。
相比传统机械键盘，K13 Pro 的矮轴和矮键帽降低了整体厚度，前缘仅 7.72mm，无需手托也能保持舒适手腕角度。同时，80% 配列在保留方向键和功能键的同时，比全尺寸键盘更节省桌面空间。
续航方面，2000mAh 电池在关背光下可提供约 130 小时使用，即便开启 RGB 也能坚持约 65 小时（最低亮度），满足一周以上的办公需求。
