# R5

## 产品定位
把无线三模连接、紧凑96%配列和长效续航结合在一起的办公型键盘

## 目标用户
- 日常办公与多设备切换用户
- 追求无线桌面整洁的桌面创作者
- 需要全尺寸功能键区的紧凑型键盘用户

## 核心卖点
- 三模连接：2.4GHz / 蓝牙5.3 / Type-C有线，多设备无缝切换
- 4000mAh大电池，关背光续航约310小时，告别频繁充电
- 99键96%配列，保留数字区与功能键，桌面空间更省

## 其他卖点
- 连接方式：2.4GHz / 蓝牙5.3 / Type-C有线
- 蓝牙模式回报率：125Hz
- 配列：ANSI，99键（96%）
- 轴体：Keychron Super机械轴，South-facing（南向）
- 键帽：Double-shot PBT，Cherry高度
- 电池：4000mAh锂聚合物电池，关背光续航约310小时（实验室数据）
- 背光：22种RGB灯效
- 无冲：有线/无线均支持全键无冲
- 多媒体键：12个
- 系统兼容：macOS / Windows / Linux
- 尺寸：399.43 x 164.78 mm，重量1125g
- 打字角度：2.37°和5.33°
- 工作温度：-10℃至50℃

## 解释
R5 是一款面向办公与多设备用户的紧凑型无线机械键盘。它保留了数字键盘和功能键区，但通过96%配列将体积控制在标准键盘的80%左右，适合桌面空间有限却又需要完整输入能力的用户。三模连接让您可以在台式机、笔记本、平板之间一键切换，4000mAh大电池配合310小时续航，即使高强度使用也无需频繁充电。相比传统全尺寸键盘，R5更节省桌面空间；相比更小的75%或60%配列，它又保留了数字区，对财务、数据录入等用户更友好。ABS外壳搭配Cherry高度PBT键帽，兼顾耐用与手感，是办公与轻游戏场景的均衡之选。
