# V0 Ultra

## 产品定位
把8K无线性能、三模连接和超轻便携结合在一起的紧凑型键盘

## 目标用户
- 追求极致便携的移动办公用户
- 桌面空间有限的极简主义者
- 需要多设备无缝切换的跨平台用户
- 对无线性能有苛刻要求的电竞玩家

## 核心卖点
- 8000Hz回报率：有线与2.4G模式下均支持8K回报率，响应速度低至0.125ms，为电竞玩家提供极致操控体验
- 超轻便携：310g重量搭配117.6×138.9mm紧凑尺寸，轻松放入背包，随时随地开启高效办公或游戏
- 超长续航：关闭背光续航长达360小时，开启RGB最低亮度也有250小时，告别频繁充电

## 其他卖点
- 连接方式：2.4GHz / Bluetooth 5.3 / Type-C 有线三模连接
- 回报率：有线及2.4G模式8000Hz，蓝牙模式125Hz
- 产品尺寸：117.6 × 138.9 mm；前高 22.1 mm，后高 29.0 mm
- 轴体：Keychron Silk POM 轴，出厂润滑，顺滑耐用
- 键帽：PBT材质（推测，规格未提供，需确认）
- 电池：1800mAh锂聚合物电池，续航360小时（背光关）/ 250小时（RGB最低亮度）
- 软件：支持QMK/VIA改键（规格未提及，需确认）
- RGB：南向RGB背光，支持灯效自定义
- 声学：PC定位板+螺丝卫星轴，提供扎实手感与纯净声音
- 系统兼容：macOS / Windows / Linux 全系统支持

## 解释
V0 Ultra 不是一把传统意义上的小键盘，而是将顶级无线性能与极致便携融合的产物。对于经常出差或桌面空间有限的用户，它310g的重量和紧凑尺寸几乎不占空间，却能提供全尺寸键盘的完整功能。
相比市面上多数无线键盘仅提供1000Hz回报率，V0 Ultra 在2.4G模式下实现了8000Hz，这是与有线键盘无异的性能表现，尤其适合对响应速度敏感的电竞玩家。同时，360小时的续航能力让用户彻底摆脱电量焦虑。
核心人群并非追求堆料的重度发烧友，而是那些需要一把‘随时能带走、性能不妥协’的键盘的移动办公者和游戏玩家。
