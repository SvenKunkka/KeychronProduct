# Q10 Pro

## 产品定位
把 CNC 铝材质感、无线自由和 75% 配列结合在一起的桌面型键盘

## 目标用户
- 追求桌面质感的机械键盘发烧友
- 多设备办公与居家办公用户
- Mac/Windows 双系统用户
- 75% 配列偏好者
- 礼品市场

## 核心卖点
- 全 CNC 铝制外壳，提供扎实稳重的手感与高级桌搭质感
- 75% 配列，紧凑布局保留 F 区与方向键，兼顾桌面空间与完整功能
- 4000mAh 大电池，关背光续航可达 300 小时，无线办公无忧

## 其他卖点
- 连接方式：蓝牙 5.1 / Type-C 有线
- 回报率：有线 1000 Hz，无线 90 Hz
- 配列：75%
- 轴体：Keychron K Pro 轴（热插拔，兼容 3 针/5 针 MX 轴）
- 键帽：KSA 双色注塑 PBT，不透明
- 电池：4000mAh 锂聚合物电池
- 续航：关背光最长 300 小时，开 RGB 最低亮度最长 100 小时
- 软件：QMK / VIA 改键支持
- RGB：南向 RGB LED
- 声学填充：PC 定位板 + 螺丝式卫星轴
- 系统兼容：macOS / Windows / Linux

## 解释
Q10 Pro 适合追求桌面质感、需要多设备切换的办公用户。全铝机身带来扎实的触感和视觉高级感，75% 配列在紧凑与功能之间取得平衡，蓝牙 5.1 可同时连接多台设备，轻松切换 Mac 与 Windows。相比普通塑料键盘，Q10 Pro 的 CNC 铝制外壳是核心差异化，搭配 KSA 球帽与南向 RGB，不仅手感出色，更成为桌面上的点睛之物。4000mAh 电池与 300 小时续航，让无线办公不再焦虑。
