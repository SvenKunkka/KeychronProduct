# K8 Ultra

## 产品定位
融合8000Hz性能、三模连接与金属质感的电竞办公键盘

## 目标用户
- 追求极致性能的电竞玩家
- 多设备办公的专业用户
- 桌面美学与质感追求者
- 机械键盘发烧友

## 核心卖点
- 8000Hz回报率：有线与2.4GHz模式下均支持8K回报率，电竞级响应速度
- Keychron Apex轴体：定制线性轴，出厂润滑，手感顺滑稳定
- CNC铝制外壳+钢制定位板：扎实稳固，兼具质感与耐用性

## 其他卖点
- 连接方式：2.4GHz / 蓝牙5.2 / Type-C有线
- 回报率：8000Hz（有线/2.4GHz），125Hz（蓝牙）
- 产品尺寸：359.2 × 129.2 mm；前高 25.55 mm，后高 31.28 mm
- 轴体：Keychron Apex Switch，热插拔设计
- 键帽：ABS材质（未标注高度，但符合标准）
- 电池：4000mAh，续航长达760小时（8K，背光关闭），230小时（8K，RGB最低亮度）
- 背光：South-facing RGB LED
- 软件：支持QMK/VIA（未明确，但Keychron常规支持）
- 系统：macOS / Windows / Linux
- 其他：螺丝固定PCB卫星轴，重1299g±10g

## 解释
K8 Ultra 不是普通的87键键盘，而是一款将电竞级性能与办公舒适性融合的TKL键盘。它适合那些白天需要高效办公、晚上需要畅快游戏的用户，8000Hz回报率确保每一次操作都精准无误。
相比传统办公键盘，K8 Ultra 提供了三模连接和超长续航，而相比纯游戏键盘，它又保留了Mac/Win双系统兼容和更低调的金属外观。CNC铝壳和钢定位板带来扎实的输入体验，适合追求品质的用户。
核心人群不是极致轻量化的便携用户，而是愿意为性能和质感买单的桌面创作者与电竞玩家。
