# Q7

## 产品定位
把全铝机身、钢制定位板和1000Hz性能结合在一起的70%配列桌面级键盘

## 目标用户
- 机械键盘发烧友
- 高端电竞玩家
- 追求桌面质感的创作者
- 收藏用户 / 礼品市场

## 核心卖点
- 全CNC铝合金外壳，一体成型，质感与刚性兼具
- 钢制定位板，提供坚实敲击手感和清脆声音反馈
- 70%紧凑配列，保留功能键区，节省桌面空间

## 其他卖点
- Type-C有线连接
- 1000Hz回报率
- Gateron G Pro轴体（整装版）
- 热插拔轴座，支持5针和3针轴体
- 双色注塑PBT键帽，OSA高度（OEM高度，SA形状），不透明
- 南向RGB背光
- 螺丝固定PCB卫星轴
- STM32L432主控（128KB Flash）
- 重量1820g±10g（整装版）
- 尺寸：341.4mm×121mm×33.8mm（后高）
- 前高20.1mm（不含键帽），倾斜角度5.2°
- 工作温度：-10℃至50℃
- 支持Mac/Win双系统

## 解释
Q7是一款为追求桌面品质和输入体验的用户打造的70%配列键盘。它采用全CNC铝合金外壳和钢制定位板，提供扎实的质感和清脆的敲击声，适合机械键盘发烧友和高端用户。与普通塑料键盘相比，Q7在材质和做工上明显更胜一筹，是桌搭和收藏的理想选择。
