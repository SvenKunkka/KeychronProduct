# K4 Max

## 产品定位
把紧凑布局、三模连接和数字小键盘结合在一起的办公键盘

## 目标用户
- 追求高效办公与数字小键盘刚需的办公用户
- 需要多设备切换（Mac/Windows/Linux）的跨平台工作者
- 喜欢紧凑布局但不想牺牲数字键区的桌面空间优化者
- 对无线稳定性和续航有要求的长时间使用者

## 核心卖点
- 96% 紧凑配列：在保留完整数字小键盘的同时，比全尺寸键盘节省约 40% 桌面空间
- 三模连接（2.4GHz/蓝牙/Type-C）：2.4GHz 模式提供稳定低延迟，蓝牙 5.1 支持多设备快速切换
- Keychron Super Switch：出厂自润轴体，手感顺滑，寿命持久，兼顾打字与游戏

## 其他卖点
- 连接方式：2.4GHz / 蓝牙 5.1 / Type-C 有线
- 回报率：蓝牙模式 125Hz
- 配列：96% (100键)，ANSI 布局
- 轴体：Keychron Super Switch（热插拔，支持自定义）
- 键帽：双色注塑 PBT，OSA 高度（OEM 轮廓带球面角度）
- 电池：4000mAh 锂聚合物电池，关背光续航约 190 小时（实验室数据）
- 软件：支持 QMK / VIA，可自定义键位、宏和灯效
- RGB：22 种背光模式，南向灯位
- 系统兼容：macOS / Windows / Linux，支持 Mac/Win 双系统键位
- 其他：12 个多媒体键，全键无冲（无线和有线均支持），三档可调脚撑（3º/7º/10º）

## 解释
K4 Max 适合需要数字小键盘但又不想被全尺寸键盘占据太多桌面的用户，比如财务、数据录入或频繁使用小键盘的办公场景。相比全尺寸键盘，它节省空间；相比 87 键或 75% 配列，它保留了小键盘的实用性，是空间与功能的平衡之选。
与自家其他型号相比，K4 Max 的差异化在于 96% 配列和三模连接，加上 4000mAh 大电池和 QMK/VIA 支持，兼顾办公和轻度游戏。对于跨平台用户，它原生支持 macOS、Windows 和 Linux，无需额外配置即可切换。
购买理由：如果你需要一把既紧凑又全能的键盘，K4 Max 提供了完整的小键盘、三模无线、长续航和高度自定义，是提升办公效率的可靠工具。
