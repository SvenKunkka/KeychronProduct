# Keychron P6

## 产品定位
把 8K 电竞性能、660 小时续航和 CNC 铝坨坨质感结合在一起的旗舰级全尺寸键盘

## 目标用户
- 追求极致性能的电竞玩家
- 需要长时间办公且注重续航的专业人士
- 桌面美学与质感并重的桌搭爱好者
- 多设备无缝切换的跨平台用户

## 核心卖点
- 8000Hz 回报率：全尺寸键盘中的性能怪兽，电竞级响应速度
- CNC 铝制机身：2.3kg 扎实分量，桌面上的质感担当
- 660 小时超长续航：关灯续航近 28 天，告别电量焦虑

## 其他卖点
- 连接方式：2.4GHz / 蓝牙 5.3 / Type-C 有线三模
- 配列：100% 全尺寸，带数字区
- 轴体：Keychron Silk POM 轴，出厂润滑
- 键帽：Cherry 高度双色注塑 PBT 键帽
- 热插拔：支持，兼容三脚/五脚轴
- 背光：South-facing RGB LED
- 卫星轴：螺丝固定 PCB 卫星轴
- 安装结构：Gasket 结构，手感软弹
- 系统兼容：macOS / iOS / Windows / Android / Linux
- 主控：Real-M300V 32-bit RTL8762G (1MB Flash)

## 解释
P6 不是一把普通的全尺寸键盘，而是把电竞级性能与桌面质感融为一体的旗舰作品。8000Hz 回报率让每一次敲击都精准反馈，2.3kg 的 CNC 铝壳带来沉稳的底座，660 小时续航更是让你在无线模式下也能放心使用数周。
相比传统办公全尺寸键盘，P6 在性能、用料和续航上全面越级；相比竞品电竞键盘，它又多了 Keychron 标志性的 Mac/Win 双系统支持和精致做工。无论你是电竞玩家、办公达人，还是追求桌面美学的收藏家，P6 都能成为你桌面上的终极之选。
