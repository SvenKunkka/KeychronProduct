# Q8 Max

## 产品定位
把铝合金工艺、三模连接和舒适人体工学结合在一起的客制化键盘

## 目标用户
- 机械键盘发烧友
- 高端电竞玩家
- 桌面美学创作者
- 多设备办公用户

## 核心卖点
- 全铝合金机身，CNC 精工一体成型，提供稳定坚固的输入平台
- Gateron Jupiter 轴体，出厂润滑，手感顺滑，寿命可靠
- 三模连接（2.4G / 蓝牙 / 有线），多设备无缝切换，办公游戏两相宜

## 其他卖点
- 连接方式：2.4GHz / 蓝牙 / Type-C 有线
- 回报率：1000Hz（2.4G 和有线），90Hz（蓝牙）
- 产品尺寸：136 × 358 mm
- 轴体：Gateron Jupiter 热插拔轴座
- 键帽：PBT 键帽（全键无冲）
- 电池：4000mAh 锂电池，续航最长 180 小时（背光关闭）或 100 小时（RGB 最低亮度）
- 软件：支持 QMK / VIA 改键，全键可编程
- RGB：南向 RGB 灯效，支持多种模式
- 声学：PC 定位板 + 多层消音棉，优化敲击音
- 系统：兼容 macOS / Windows / Linux

## 解释
Q8 Max 适合追求桌面质感与性能平衡的用户。铝合金外壳提供扎实手感，三模连接满足多设备切换需求，Gateron Jupiter 轴体保证顺滑输入体验。相比入门塑料键盘，Q8 Max 在材质、做工和连接性能上都有显著提升，是进阶玩家的理想选择。
