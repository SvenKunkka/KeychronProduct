# B6 Pro

## 产品定位
超薄轻便、多设备兼容的 100% 配列无线办公键盘

## 目标用户
- 追求极致轻薄便携的移动办公用户
- 需要多设备无缝切换的跨平台工作者
- 注重桌面整洁与低噪音环境的静音办公用户
- 初次接触机械键盘、追求舒适打字体验的入门用户

## 核心卖点
- 极致轻薄设计：前高仅 5.2mm，重量仅 623g，轻松放入公文包或背包
- 17 个多媒体快捷键：一键控制音量、播放、邮件等，提升办公效率
- 多平台无缝兼容：支持 macOS、iOS、Windows、Android、Linux，一键切换

## 其他卖点
- 连接方式：蓝牙 5.2 无线连接
- 配列：ANSI 109 键（100% 全尺寸）
- 键帽：ABS 材质
- 电池：800 mAh 锂聚合物电池，充电时间约 2.5 小时
- 系统兼容：macOS / iOS / Windows / Android / Linux
- 背光：无背光（Non-Backlit）
- 尺寸：429 x 130 mm，重量 623 g
- 打字角度：3.2º，符合人体工学
- 工作温度：-10 至 50℃

## 解释
B6 Pro 不是一款游戏键盘，而是一款为移动办公和多设备用户打造的轻薄生产力工具。它拥有极低的前高和轻巧的机身，即使长时间打字也不易疲劳，同时 17 个多媒体键让常用操作一键直达。
相比传统全尺寸键盘，B6 Pro 在保持 100% 配列完整功能的同时，将厚度和重量控制到极致，更适合需要频繁携带键盘的商务人士或桌面空间有限的用户。
核心人群不是追求 RGB 和热插拔的发烧友，而是注重实用、便携和跨平台体验的办公用户。如果你需要一个能陪伴你穿梭于办公室、咖啡馆和家中，且兼容所有设备的键盘，B6 Pro 是理想之选。
