# V1 Ultra

## 产品定位
把 8K 回报率性能、三模连接效率和紧凑设计结合在一起的桌面型键盘

## 目标用户
- 追求极致性能的电竞玩家
- 需要多设备无缝切换的办公用户
- 注重桌面整洁与便携性的极简主义者
- 初次尝试高性能键盘的入门用户

## 核心卖点
- 8000 Hz 回报率（有线/2.4G），电竞级响应速度
- 三模连接（2.4G/蓝牙/有线），多设备无缝切换
- 4000 mAh 大电池，蓝牙续航最长 660 小时

## 其他卖点
- 连接方式：2.4 GHz / Bluetooth 5.3 / Type-C 有线
- 回报率：8000 Hz（有线/2.4G），125 Hz（蓝牙）
- 产品尺寸：148.7 × 328.5 mm；前高 21.5 mm
- 轴体：Keychron Silk POM 轴，出厂润滑
- 卫星轴：螺丝固定 PCB 卫星轴
- 键帽：PBT 材质（根据规格推断，未明确，但常见）
- 电池：4000 mAh 锂聚合物电池
- 软件：支持 QMK/VIA 改键（根据品牌惯例，但规格未提，需谨慎）
- RGB：南向 RGB LED，支持多种灯效
- 声学填充：PC 定位板，内部填充（规格未明确，但可提）
- 系统兼容：macOS / Windows / Linux

## 解释
V1 Ultra 不是一款传统意义上的入门键盘，而是将旗舰级性能与实用功能融合的产物。对于电竞玩家，8K 回报率带来极致的响应速度；对于办公用户，三模连接和超长续航让多设备切换变得高效；对于桌面美学追求者，紧凑设计和塑料外壳的轻量化（770g）也易于融入各种桌面环境。相比其他同价位产品，V1 Ultra 的核心优势在于其 8K 回报率与三模的罕见组合，以及 Keychron 一贯的 Mac/Win 兼容性，适合那些既要性能又要便利的用户。
