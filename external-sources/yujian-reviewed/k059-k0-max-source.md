# K0 Max

## 产品定位
支持 QMK 的低矮型独立数字小键盘。

## 核心卖点
- 独立数字小键盘：27 键，带宏按键列与旋钮
- 三模连接：2.4 GHz / Bluetooth 5.3 / Type-C 有线
- 2.4 GHz 与有线模式支持 1000 Hz 回报率

## 其他卖点
- 连接方式：2.4 GHz / Bluetooth 5.3 / Type-C 有线
- 配列：独立数字小键盘（27 键）
- 回报率：1000 Hz（2.4 GHz 与有线）；125 Hz（Bluetooth）
