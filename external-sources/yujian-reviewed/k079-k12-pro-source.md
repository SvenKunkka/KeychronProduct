# K12 Pro

## 产品定位
把 60% 便携、蓝牙 5.1 无线和 QMK 可编程结合在一起的客制化机械键盘

## 目标用户
- 追求极致便携与桌搭简洁的 60% 配列爱好者
- 多设备办公、需要蓝牙无线切换的 macOS/Windows 双系统用户
- 初次尝试客制化、想体验 QMK 可编程的入门玩家

## 核心卖点
- QMK/VIA 全键可编程：支持自定义键位、宏和层，配合 12 个多媒体键，小配列也能高效操控
- 双模连接：蓝牙 5.1 与 Type-C 有线，支持 3 台设备无缝切换，办公与游戏灵活切换
- 4000mAh 大电池：关背光续航约 260 小时，开 RGB 最低亮度约 130 小时，告别电量焦虑

## 其他卖点
- 连接方式：蓝牙 5.1 + Type-C 有线
- 回报率：有线 1000Hz / 无线 90Hz
- 配列：61 键 60% ANSI 布局
- 轴体：South-facing 轴体，支持 PCB 螺丝固定卫星轴
- 键帽：OSA 高度（OEM 球面角度）
- 背光：22 种 RGB 灯效
- 电池：4000mAh 锂聚合物电池
- 续航：关背光约 260 小时 / 开 RGB 最低亮度约 130 小时
- 系统：macOS/Windows/Linux 兼容
- 材质：ABS 或 ABS+铝框（可选），钢制定位板
- 尺寸：293×102.8mm（塑壳）/ 298.5×107.5mm（铝壳）
- 重量：737g（塑壳）
- 工作环境：-10 至 50℃

## 解释
K12 Pro 是 60% 配列中的全能选手：它既有 60% 的极致紧凑，又有蓝牙无线的自由，还有 QMK/VIA 的深度客制化能力。对于想要在桌搭中节省空间、同时不妥协功能性的用户，它比普通 60% 键盘更强大，比 65% 或 75% 更便携。
相比同尺寸竞品，K12 Pro 的 4000mAh 电池和 260 小时续航是显著优势，而 OSA 键帽和钢制定位板提供了扎实的打字手感。无论你是 macOS 用户需要蓝牙切换，还是 Windows 玩家想要有线低延迟，它都能满足。
