# V7

## 产品定位
更轻便、更耐用、更容易上手的70%配列办公游戏键盘

## 目标用户
- 追求性价比的入门机械键盘用户
- 办公与轻度游戏兼顾的日常用户
- 对Mac/Win双系统兼容有需求的用户

## 核心卖点
- 70%配列，紧凑布局节省桌面空间，同时保留方向键与功能键，兼顾办公与游戏
- 钢制定位板与Tray Mount结构，提供扎实稳定的敲击手感，耐用性强
- 支持热插拔，兼容5针与3针轴体，自由更换轴体，轻松定制手感

## 其他卖点
- 连接方式：Type-C有线连接
- 回报率：1000 Hz
- 配列：70%
- 轴体：Keychron K Pro（整装版）
- 键帽：Double-shot PBT键帽，不透明，OSA高度（OEM高度，SA形状）
- 背光：South-facing RGB LED
- 主控：Ultra-low-power ARM Cortex-M4 32-bit STM32L432（128KB Flash）
- 卫星轴：Screw-in PCB stabilizers
- 系统兼容：Mac/Win双系统
- 尺寸：341.85×117×25.75 mm（不含键帽）
- 重量：845±10 g（整装版）

## 解释
V7适合预算有限但希望体验机械键盘的入门用户，以及需要紧凑布局节省桌面空间的办公用户。70%配列在保留核心功能的同时，比全尺寸更小巧，适合桌面空间有限的场景。
相比同价位产品，V7采用钢制定位板与Tray Mount结构，手感扎实稳定，且支持热插拔，可玩性高。同时，其键帽为OSA高度，兼顾OEM的舒适与SA的饱满，适合长时间打字。
对于需要多设备切换的Mac/Win用户，V7提供双系统兼容，配合Type-C有线连接，即插即用，无需额外驱动。
