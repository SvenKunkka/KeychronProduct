# K4 Pro

## 产品定位
面向多设备办公用户的96%配列无线机械键盘

## 目标用户
- 追求高效办公与多设备切换的职场用户
- 需要数字小键盘但桌面空间有限的紧凑型用户
- 入门机械键盘爱好者，追求手感与功能平衡

## 核心卖点
- 96%配列保留数字小键盘，节省桌面空间
- 支持蓝牙5.1三设备切换，办公效率倍增
- 4000mAh大电池，关背光续航约260小时

## 其他卖点
- 连接方式：蓝牙5.1和Type-C有线
- 回报率：有线1000Hz，无线90Hz
- 轴体：South-facing，支持热插拔
- 键帽：OSA高度，PBT材质
- 背光：22种RGB灯效
- 系统兼容：macOS/Windows/Linux
- 无冲模式：无线和有线均支持
- 多媒体键：12个
- 打字角度：3º、7º、10º可调
- 工作环境：-10至50℃

## 解释
K4 Pro适合需要数字小键盘但桌面空间有限的用户，它将96%配列与无线蓝牙结合，兼顾办公效率与桌面整洁。相比全尺寸键盘，它节省20%空间；相比87键，它保留了数字区。4000mAh电池和260小时续航，让用户摆脱频繁充电的烦恼。
