# J1

## 产品定位
更薄、更轻、更易携带的 75% 配列矮轴机械键盘

## 目标用户
- 办公+轻游戏用户
- 多设备办公用户
- 追求便携与桌面整洁的用户
- 第一次购买矮轴键盘的用户

## 核心卖点
- 超薄矮轴设计，前高仅 15.13mm，搭配低剖面双色注塑 PBT 键帽，兼顾手感与便携
- 三模连接（2.4GHz / 蓝牙 5.2 / Type-C），支持最多 3 台设备无缝切换，办公效率倍增
- 2000mAh 电池，关背光续航约 3 周，Type-C 快充，告别电量焦虑

## 其他卖点
- 连接方式：2.4GHz / 蓝牙 5.2 / Type-C 有线，三模自由切换
- 回报率：蓝牙模式 125Hz，有线/2.4G 模式 1000Hz
- 配列：82 键（75%），ANSI 布局，紧凑实用
- 轴体：Keychron 矮轴（红/茶可选），线性或段落手感，触发灵敏
- 键帽：低剖面双色注塑 PBT 键帽，耐磨不打油
- 电池：2000mAh 可充电锂电池，关背光续航约 3 周（实验室数据）
- 背光：22 种 RGB 灯效，支持自定义
- 无冲：有线/无线均支持全键无冲
- 系统：macOS / Windows / Linux 全兼容，支持 Mac/Win 键位切换
- 多媒体键：12 个，快捷控制音量、播放等

## 解释
J1 不是一款厚重的传统机械键盘，而是一款为现代办公与轻游戏场景打造的轻薄矮轴键盘。它的前高仅 15.13mm，比普通机械键盘薄 30% 以上，配合低剖面键帽，即使长时间输入也能保持手腕自然姿态，减少疲劳。
相比 Keychron 其他系列，J1 更注重便携与桌面整洁：661g 的重量、紧凑的 75% 配列，以及三模连接，让你轻松在台式机、笔记本、平板之间切换。2000mAh 电池带来约 3 周的续航，即便出差也无需频繁充电。
J1 的核心用户不是追求极致手感的发烧友，而是那些需要一把‘够用、好用、不占地方’的键盘的办公族和轻游戏玩家。它用更低的门槛，让更多人体验到机械键盘的爽快，同时保持 Keychron 一贯的做工与兼容性。
