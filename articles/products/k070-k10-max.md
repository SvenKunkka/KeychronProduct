## 产品定位

面向多设备办公用户的 108 配列三模机械键盘 [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)

## 目标用户

- 追求高效办公与多设备切换的职场人士 [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)
- 偏好全尺寸配列与数字小键盘的实用主义者 [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)
- 兼顾办公与轻度游戏、注重性价比的用户 [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)
- Mac 与 Windows 双系统用户 [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)

## 核心卖点

- 三模连接（2.4GHz/蓝牙/有线），蓝牙模式回报率 90Hz [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)
- 4000mAh 大电池，关背光续航约 190 小时，告别频繁充电 [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)
- 双系统原生支持（macOS/Win），配 12 个多媒体键，适配 Mac 键位 [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)

## 其他卖点

- 连接方式：2.4GHz / 蓝牙 5.1 / Type-C 有线 [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)
- 回报率：蓝牙模式 90Hz [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)
- 配列：108 键（100%）ANSI 布局 [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)
- 轴体：Keychron Super / Apex 机械轴（South-facing） [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)
- 键帽：双色注塑 PBT，OSA 高度（OEM 球形角度） [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)
- 电池：4000mAh 锂聚合物电池，关背光续航约 190 小时 [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)
- 软件：支持 QMK / VIA 改键 [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)
- RGB：22 种背光模式 [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)
- 声学：多层消音填充 [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)
- 系统：macOS / Windows / Linux [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)
- 其他：全键无冲（无线/有线），三档角度调节（3.43°/7.26°/10.06°） [已审核来源](../../external-sources/yujian-reviewed/k070-k10-max-source.md)
