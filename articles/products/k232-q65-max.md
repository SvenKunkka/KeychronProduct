## 核心卖点

- 铝合金外壳，CNC 一体成型，质感与坚固兼备，为桌面增添高级感 [已审核来源](../../external-sources/yujian-reviewed/k232-q65-max-source.md)
- 2.4GHz 无线连接，1000Hz 回报率，媲美有线的低延迟体验，游戏办公两不误 [已审核来源](../../external-sources/yujian-reviewed/k232-q65-max-source.md)
- 4000mAh 大电池，关背光续航长达 180 小时，摆脱频繁充电烦恼 [已审核来源](../../external-sources/yujian-reviewed/k232-q65-max-source.md)

## 其他卖点

- 连接方式：2.4GHz / 蓝牙 5.1 / Type-C 有线，三模切换 [已审核来源](../../external-sources/yujian-reviewed/k232-q65-max-source.md)
- 回报率：1000Hz（2.4GHz / 有线），90Hz（蓝牙） [已审核来源](../../external-sources/yujian-reviewed/k232-q65-max-source.md)
- 配列：65% 紧凑布局，节省桌面空间 [已审核来源](../../external-sources/yujian-reviewed/k232-q65-max-source.md)
- 轴体：Gateron Jupiter 轴，热插拔设计，兼容 3pin/5pin MX 轴 [已审核来源](../../external-sources/yujian-reviewed/k232-q65-max-source.md)
- 键帽：KSA 双色注塑 PBT 键帽，耐磨不打油 [已审核来源](../../external-sources/yujian-reviewed/k232-q65-max-source.md)
- 电池：4000mAh 锂电池，充电时间约 5 小时 [已审核来源](../../external-sources/yujian-reviewed/k232-q65-max-source.md)
- 软件：支持 QMK / VIA 改键，全键无冲 [已审核来源](../../external-sources/yujian-reviewed/k232-q65-max-source.md)
- RGB：22 种灯效，南向 RGB LED [已审核来源](../../external-sources/yujian-reviewed/k232-q65-max-source.md)
- 声学：PCB 卫星轴，填充材料优化声音 [已审核来源](../../external-sources/yujian-reviewed/k232-q65-max-source.md)
- 系统：兼容 macOS / Windows / Linux [已审核来源](../../external-sources/yujian-reviewed/k232-q65-max-source.md)
