## 核心卖点

- 全铝合金机身，CNC 精工一体成型，提供稳定坚固的输入平台 [已审核来源](../../external-sources/yujian-reviewed/k235-q8-max-source.md)
- Gateron Jupiter 轴体，出厂润滑，手感顺滑，寿命可靠 [已审核来源](../../external-sources/yujian-reviewed/k235-q8-max-source.md)
- 三模连接（2.4G / 蓝牙 / 有线），多设备无缝切换，办公游戏两相宜 [已审核来源](../../external-sources/yujian-reviewed/k235-q8-max-source.md)

## 其他卖点

- 连接方式：2.4GHz / 蓝牙 / Type-C 有线 [已审核来源](../../external-sources/yujian-reviewed/k235-q8-max-source.md)
- 回报率：1000Hz（2.4G 和有线），90Hz（蓝牙） [已审核来源](../../external-sources/yujian-reviewed/k235-q8-max-source.md)
- 产品尺寸：136 × 358 mm [已审核来源](../../external-sources/yujian-reviewed/k235-q8-max-source.md)
- 轴体：Gateron Jupiter 热插拔轴座 [已审核来源](../../external-sources/yujian-reviewed/k235-q8-max-source.md)
- 键帽：PBT 键帽（全键无冲） [已审核来源](../../external-sources/yujian-reviewed/k235-q8-max-source.md)
- 电池：4000mAh 锂电池，续航最长 180 小时（背光关闭）或 100 小时（RGB 最低亮度） [已审核来源](../../external-sources/yujian-reviewed/k235-q8-max-source.md)
- 软件：支持 QMK / VIA 改键，全键可编程 [已审核来源](../../external-sources/yujian-reviewed/k235-q8-max-source.md)
- RGB：南向 RGB 灯效，支持多种模式 [已审核来源](../../external-sources/yujian-reviewed/k235-q8-max-source.md)
- 声学：PC 定位板 + 多层消音棉，优化敲击音 [已审核来源](../../external-sources/yujian-reviewed/k235-q8-max-source.md)
- 系统：兼容 macOS / Windows / Linux [已审核来源](../../external-sources/yujian-reviewed/k235-q8-max-source.md)
