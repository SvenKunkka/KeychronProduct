## 产品定位

更薄、更轻、更高效的 104 键全尺寸矮轴机械键盘 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)

## 目标用户

- 办公用户：需要全尺寸布局和数字小键盘，追求高效输入与多设备切换 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)
- 轻游戏玩家：需要低延迟与RGB背光，但不想牺牲办公舒适度 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)
- 桌面整洁爱好者：偏好无线连接与紧凑全尺寸设计，减少线缆杂乱 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)
- Mac/iOS 用户：需要原生 Mac 键位与多系统兼容 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)
- 入门机械键盘用户：想体验机械手感但预算有限，且偏好矮轴 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)

## 核心卖点

- 矮轴设计：采用 Low Profile Gateron 机械轴或 Keychron 光轴，键程更短，响应更快，兼顾手感与便携 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)
- 全尺寸配列：104 键完整布局，保留数字小键盘与 12 个多媒体键，办公效率直接拉满 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)
- 双模连接：蓝牙 5.1 与 Type-C 有线，支持 3 台设备快速切换，多设备办公无缝衔接 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)

## 其他卖点

- 连接方式：蓝牙 5.1 + Type-C 有线 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)
- 回报率：有线 1000 Hz / 无线 90 Hz [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)
- 配列：ANSI 104 键 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)
- 轴体：Low Profile Gateron 机械轴 / Keychron 光轴 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)
- 键帽：ABS 背光透光键帽 / PBT 非透光键帽 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)
- 电池：2000mAh 锂聚合物电池 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)
- 背光：18 种灯效，4 级 RGB 亮度可调 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)
- 系统：Windows / Android / Mac / iOS 全兼容 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)
- 材质：ABS 主体 + 铝合金边框，兼顾轻量与质感 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)
- 重量：约 673g，便于携带 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)
- 尺寸：435 x 120 mm，紧凑全尺寸 [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)
- 工作温度：-10 至 50℃ [已审核来源](../../external-sources/yujian-reviewed/k127-k5-se-source.md)
