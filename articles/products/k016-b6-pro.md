## 目标用户

- 注重桌面整洁与低噪音环境的静音办公用户 [已审核来源](../../external-sources/yujian-reviewed/k016-b6-pro-source.md)
- 初次接触机械键盘、追求舒适打字体验的入门用户 [已审核来源](../../external-sources/yujian-reviewed/k016-b6-pro-source.md)

## 核心卖点

- 极致轻薄设计：前高仅 5.2mm，重量仅 623g，轻松放入公文包或背包 [已审核来源](../../external-sources/yujian-reviewed/k016-b6-pro-source.md)
- 17 个多媒体快捷键：一键控制音量、播放、邮件等，提升办公效率 [已审核来源](../../external-sources/yujian-reviewed/k016-b6-pro-source.md)
- 多平台无缝兼容：支持 macOS、iOS、Windows、Android、Linux，一键切换 [已审核来源](../../external-sources/yujian-reviewed/k016-b6-pro-source.md)

## 其他卖点

- 连接方式：蓝牙 5.2 无线连接 [已审核来源](../../external-sources/yujian-reviewed/k016-b6-pro-source.md)
- 配列：ANSI 109 键（100% 全尺寸） [已审核来源](../../external-sources/yujian-reviewed/k016-b6-pro-source.md)
- 键帽：ABS 材质 [已审核来源](../../external-sources/yujian-reviewed/k016-b6-pro-source.md)
- 电池：800 mAh 锂聚合物电池，充电时间约 2.5 小时 [已审核来源](../../external-sources/yujian-reviewed/k016-b6-pro-source.md)
- 系统兼容：macOS / iOS / Windows / Android / Linux [已审核来源](../../external-sources/yujian-reviewed/k016-b6-pro-source.md)
- 背光：无背光（Non-Backlit） [已审核来源](../../external-sources/yujian-reviewed/k016-b6-pro-source.md)
- 尺寸：429 x 130 mm，重量 623 g [已审核来源](../../external-sources/yujian-reviewed/k016-b6-pro-source.md)
- 打字角度：3.2º，符合人体工学 [已审核来源](../../external-sources/yujian-reviewed/k016-b6-pro-source.md)
- 工作温度：-10 至 50℃ [已审核来源](../../external-sources/yujian-reviewed/k016-b6-pro-source.md)
