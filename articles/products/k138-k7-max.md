## 产品定位

把低剖面手感、三模连接和紧凑 65% 配列结合在一起的便携型机械键盘 [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)

## 目标用户

- 65% 配列爱好者 / 桌面空间紧凑用户 [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)
- 多设备办公用户（Mac/Windows/Linux 三系统切换） [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)
- 需要 2.4G/蓝牙/有线三模连接的游戏玩家 [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)
- 追求低剖面手感与便携性的移动办公人群 [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)

## 核心卖点

- 低剖面设计：Gateron 矮轴 + 低剖面双色 PBT 键帽，触发行程更短，长时间打字更省力 [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)
- 三模连接：2.4GHz / 蓝牙 5.1 / Type-C 有线，多设备间无缝切换，办公游戏两不误 [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)
- 全键无冲：无线与有线模式均支持全键无冲，游戏操作精准不冲突 [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)

## 其他卖点

- 连接方式：2.4GHz / 蓝牙 5.1 / Type-C 有线 [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)
- 回报率：蓝牙模式 90Hz [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)
- 配列：65% (68键) ANSI 布局 [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)
- 轴体：Gateron 矮轴（North-facing） [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)
- 键帽：低剖面双色 PBT [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)
- 电池：1550mAh 锂电池，关背光续航约 73 小时（实验室数据） [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)
- 背光：22 种 RGB 灯效，支持自定义 [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)
- 系统兼容：macOS / Windows / Linux [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)
- 材质：ABS 底壳 + 铝制边框 [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)
- 尺寸：306 x 97.5mm，重 436g，前高 8.8mm，后高 13.2mm [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)
- 打字角度：3.37° / 4.4° / 7.39° 可调 [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)
- 工作温度：-10℃ 至 50℃ [已审核来源](../../external-sources/yujian-reviewed/k138-k7-max-source.md)
