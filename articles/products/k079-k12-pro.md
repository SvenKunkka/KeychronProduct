## 产品定位

把 60% 便携、蓝牙 5.1 无线和 QMK 可编程结合在一起的客制化机械键盘 [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)

## 目标用户

- 追求极致便携与桌搭简洁的 60% 配列爱好者 [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)
- 多设备办公、需要蓝牙无线切换的 macOS/Windows 双系统用户 [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)
- 初次尝试客制化、想体验 QMK 可编程的入门玩家 [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)

## 核心卖点

- QMK/VIA 全键可编程：支持自定义键位、宏和层，配合 12 个多媒体键，小配列也能高效操控 [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)
- 双模连接：蓝牙 5.1 与 Type-C 有线，支持 3 台设备无缝切换，办公与游戏灵活切换 [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)
- 4000mAh 大电池：关背光续航约 260 小时，开 RGB 最低亮度约 130 小时，告别电量焦虑 [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)

## 其他卖点

- 连接方式：蓝牙 5.1 + Type-C 有线 [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)
- 回报率：有线 1000Hz / 无线 90Hz [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)
- 配列：61 键 60% ANSI 布局 [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)
- 轴体：South-facing 轴体，支持 PCB 螺丝固定卫星轴 [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)
- 键帽：OSA 高度（OEM 球面角度） [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)
- 背光：22 种 RGB 灯效 [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)
- 电池：4000mAh 锂聚合物电池 [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)
- 续航：关背光约 260 小时 / 开 RGB 最低亮度约 130 小时 [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)
- 系统：macOS/Windows/Linux 兼容 [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)
- 材质：ABS 或 ABS+铝框（可选），钢制定位板 [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)
- 尺寸：293×102.8mm（塑壳）/ 298.5×107.5mm（铝壳） [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)
- 重量：737g（塑壳） [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)
- 工作环境：-10 至 50℃ [已审核来源](../../external-sources/yujian-reviewed/k079-k12-pro-source.md)
