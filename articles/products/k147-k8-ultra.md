## 核心卖点

- 8000Hz回报率：有线与2.4GHz模式下均支持8K回报率，电竞级响应速度 [已审核来源](../../external-sources/yujian-reviewed/k147-k8-ultra-source.md)
- Keychron Apex轴体：定制线性轴，出厂润滑，手感顺滑稳定 [已审核来源](../../external-sources/yujian-reviewed/k147-k8-ultra-source.md)
- CNC铝制外壳+钢制定位板：扎实稳固，兼具质感与耐用性 [已审核来源](../../external-sources/yujian-reviewed/k147-k8-ultra-source.md)

## 其他卖点

- 连接方式：2.4GHz / 蓝牙5.2 / Type-C有线 [已审核来源](../../external-sources/yujian-reviewed/k147-k8-ultra-source.md)
- 回报率：8000Hz（有线/2.4GHz），125Hz（蓝牙） [已审核来源](../../external-sources/yujian-reviewed/k147-k8-ultra-source.md)
- 产品尺寸：359.2 × 129.2 mm；前高 25.55 mm，后高 31.28 mm [已审核来源](../../external-sources/yujian-reviewed/k147-k8-ultra-source.md)
- 轴体：Keychron Apex Switch，热插拔设计 [已审核来源](../../external-sources/yujian-reviewed/k147-k8-ultra-source.md)
- 键帽：ABS材质（未标注高度，但符合标准） [已审核来源](../../external-sources/yujian-reviewed/k147-k8-ultra-source.md)
- 电池：4000mAh，续航长达760小时（8K，背光关闭），230小时（8K，RGB最低亮度） [已审核来源](../../external-sources/yujian-reviewed/k147-k8-ultra-source.md)
- 背光：South-facing RGB LED [已审核来源](../../external-sources/yujian-reviewed/k147-k8-ultra-source.md)
- 软件：支持QMK/VIA（未明确，但Keychron常规支持） [已审核来源](../../external-sources/yujian-reviewed/k147-k8-ultra-source.md)
- 系统：macOS / Windows / Linux [已审核来源](../../external-sources/yujian-reviewed/k147-k8-ultra-source.md)
- 其他：螺丝固定PCB卫星轴，重1299g±10g [已审核来源](../../external-sources/yujian-reviewed/k147-k8-ultra-source.md)
