## 产品定位

把轻薄便携、三模连接和舒适打字角度结合在一起的 75% 配列矮轴键盘 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)

## 目标用户

- 追求轻便与高效的多设备办公用户 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)
- 需要紧凑布局但保留完整功能的桌面创作者 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)
- macOS 与 Windows 双系统切换的混合办公人群 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)
- 注重桌面整洁与低姿态美学的极简主义者 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)

## 核心卖点

- 低剖面设计：11mm 前高，配合 2.5º/4.2º/6.5º 三档可调脚撑，兼顾轻薄与人体工学 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)
- 三模连接：2.4GHz / 蓝牙 5.1 / Type-C 有线，支持多设备无缝切换，蓝牙模式 90Hz 回报率保障流畅输入 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)
- 矮轴手感：Gateron 矮轴与 Keychron 矮轴可选，触发快速，适合长时间打字 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)

## 其他卖点

- 连接方式：2.4GHz / 蓝牙 5.1 / Type-C 有线 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)
- 回报率：蓝牙模式 90Hz [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)
- 配列：84 键 (75%)，ANSI 布局 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)
- 轴体：Gateron 矮轴 / Keychron 矮轴，North-facing 设计 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)
- 键帽：低剖面双色注塑 PBT，耐磨不打油 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)
- 电池：1550mAh 锂聚合物电池，续航持久 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)
- 背光：22 种 RGB 灯效，支持自定义 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)
- 系统兼容：macOS / Windows / Linux，支持 Mac/Win 双系统快捷键 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)
- 多媒体键：12 个，方便快捷操作 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)
- 无冲模式：无线/有线均支持全键无冲 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)
- 材质：ABS + 铝合金边框，兼顾轻量与质感 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)
- 尺寸：306 x 116 mm，重量 525g，便携性佳 [已审核来源](../../external-sources/yujian-reviewed/k106-k3-max-source.md)
