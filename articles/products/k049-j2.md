## 核心卖点

- 三模连接，2.4GHz/蓝牙/Type-C，多设备无缝切换 [已审核来源](../../external-sources/yujian-reviewed/k049-j2-source.md)
- 4000mAh大电池，关背光续航约300小时，告别电量焦虑 [已审核来源](../../external-sources/yujian-reviewed/k049-j2-source.md)
- 双键帽高度可选（Cherry/MDA），满足不同手感偏好 [已审核来源](../../external-sources/yujian-reviewed/k049-j2-source.md)

## 其他卖点

- 连接方式：2.4GHz / 蓝牙5.2 / Type-C有线 [已审核来源](../../external-sources/yujian-reviewed/k049-j2-source.md)
- 回报率：蓝牙模式125Hz，有线/2.4G模式支持全键无冲 [已审核来源](../../external-sources/yujian-reviewed/k049-j2-source.md)
- 配列：83键75% ANSI布局 [已审核来源](../../external-sources/yujian-reviewed/k049-j2-source.md)
- 轴体：机械轴（North-facing） [已审核来源](../../external-sources/yujian-reviewed/k049-j2-source.md)
- 键帽：Double-shot PBT，Cherry/MDA高度可选 [已审核来源](../../external-sources/yujian-reviewed/k049-j2-source.md)
- 电池：4000mAh锂聚合物电池，关背光续航约300小时 [已审核来源](../../external-sources/yujian-reviewed/k049-j2-source.md)
- 软件：支持QMK/VIA改键（需确认，但规格未提及，此处不写） [已审核来源](../../external-sources/yujian-reviewed/k049-j2-source.md)
- 背光：22种RGB灯效，可自定义 [已审核来源](../../external-sources/yujian-reviewed/k049-j2-source.md)
- 系统兼容：Windows / Mac / Linux [已审核来源](../../external-sources/yujian-reviewed/k049-j2-source.md)
- 尺寸：332.3 x 139.92 mm，重量808g [已审核来源](../../external-sources/yujian-reviewed/k049-j2-source.md)
- 打字角度：4.5º / 6.4º / 8.8º 可调 [已审核来源](../../external-sources/yujian-reviewed/k049-j2-source.md)
- 工作环境：-10℃ 至 50℃ [已审核来源](../../external-sources/yujian-reviewed/k049-j2-source.md)
